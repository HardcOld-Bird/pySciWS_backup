# A.a4 拆解改进派单（tb-5 返工第 3 轮）

## 拆解

依据 a2 五件套与 jury 裁决 A，拆解 **a5 devops 改进实施**工单（三件，按依赖排序）：

**工单 1：`slides audit` 机械审计器 + deck-spec 载体（骨干）**
- spec schema：每 deck YAML——不变量（装饰三层指纹、字体全槽 latin+ea+panose、版式、
  动画指针）+ 图槽（占位符指纹 md5/尺寸、内容锚、原文图号、来源文件、裁切参数）。
- `pysci-compose slides audit <deck> --spec <spec>`：逐项机械核验输出 PASS/FAIL 表——
  装饰层存在性与指纹、每标题/胶囊/正文 runPr 含 `<a:ea>`、图槽内容指纹比对、引用框
  规则（复用 slides layout）、标题公式（复用几何判据）；判不了的降级「人工确认」行留勾。
- 验收：正反例 spec×deck 各 ≥1（缺装饰/缺 ea/图槽错配→FAIL 行可复现）；真实 deck 试跑。

**工单 2：提取管线补缺**
- fig 区上限可配（放开 6）+ `figures.json` 增 figN↔原文图号映射 + 用户批注 bbox 落参
  （NatMater 整页 PDF 案）+ 整页图检测提示；对 RPP 86 Fig.7、PRL 123 Fig.2 重提验证。
- 验收：三案例（Fig.7/Fig.2/整页裁切）产出正确入位；figures.json 映射可查。

**工单 3：字体全槽 + 任务书切片辅助**
- 字体写框工具/公共 API：latin+ea+cs+panose 照模板 rPr 复制（绕 python-pptx latin-only），
  audit 校验接线；
- 任务书 spec 切片辅助（可选 CLI 或规范文档）：按页/工序切 spec 生成任务书正文骨架，
  现状断言强制带机械读数的书写规范写入 orchestration 拆解教义（plan-decomposition 增补）。
- 验收：新建框经工具写出即含 ea；教义增补 lint 可引用。

全量测试 + ruff + 预算 + sync 随单。b_spec（spec 汇编）与 B 段返工不属本单。

## 结论

三工单覆盖五件套机械面（1=spec+audit 骨干、2=提取能力、3=字体与流程教义）；返工用例
即验收现场。交 a5 devops 实施。
