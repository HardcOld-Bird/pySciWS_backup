# A.a1 成因分析（tb-5 返工第 1 轮）

## 成因分析

### 一、Science 334, 333 (2011) 获取失败（用户重点质询）

**实测取证（2026-10-19，本机，直连未走代理）**：
- `curl -L https://www.science.org/doi/pdf/10.1126/science.1210713` 连打 3 次：**全部
  HTTP 403**，响应体 5,509B HTML，`<title>Just a moment...</title>`、引用
  `challenges.cloudflare.com`——**Cloudflare JS 挑战页（bot 防护）**。
- 换浏览器 UA、试 `epdf` 形态再打 2 次：仍 403（5,723B 同挑战页）。
- 结论：**不是「网络不稳定」**——本机 curl 5 连击稳定被挑战；所谓不稳定感来自
  Cloudflare 自适应评分对不同客户端/时段松紧不一（用户浏览器得分高即放行）。

**为何用户浏览器能过、我们不能**：Cloudflare JS 挑战须由**真浏览器执行 JS**换
`cf_clearance` cookie；校园网下机构认证（SSO）是透明的，用户浏览器拿 cookie 后直接
到 PDF。纯 HTTP 客户端（requests/curl，无论 UA）在 TLS 指纹与 JS 挑战双检下必 403——
这与 backlog #232 已实证的「curl 200 vs requests 403」（APS 仅 TLS 指纹检）不同，
Science 是**更严的 JS 挑战**，curl 也过不去。

**我们链路的断点**：`browser_fetch.py` 的设计目标正是「Playwright 复用本机 Chrome/Edge
过 CF」（模块头注释明示），且 playwright 依赖已装（实测 import OK）。但 l2 当日六渠道
尝试记录中**没有浏览器通道的尝试痕迹**（渠道表：本地/Zotero/Science 直链 403/read
Cloudflare/arXiv 无/S2 CLOSED）——断点在**调用链**而非能力缺失，候选疑点（留 a5 实证
定位）：①`read` 的渠道候选序里浏览器通道排在末位且前序失败后未被触发或静默失败；
②headless 默认启动被 CF 指纹识别（工具已备 `--headed` 形态）；③挑战页出现后未等待
JS 完成即判失败。此外 Science 无专属 PublisherAdapter（仅 APS+generic），但 generic
兜底不阻下载，属次要。

**可修性评估：高**。所需组件（Playwright、本机浏览器、PDF 下载命令、CF 挑战特征词表
`"checking your browser"` 等）已存在，缺的是「挑战等待→clearance→PDF 落盘」链路打通
＋science.org 适配＋按用户提示的重试语义（其观察的不稳定恰可由 N 次重试吸收）。

### 二、PPT 版面与预设差距（用户 3 项机制性建议 + 8 项逐页改法）

- **标题字间距/分散对齐**：w1 预设只记了「框宽随字数自适应、algn=dist」的实测值，未把
  「字间距是目的、框长是手段」提炼为可复用规则；焦点块胶囊标题的分散对齐需求未被识别
  （背景色框+左对齐=右侧可见空白）。
- **缩略引用文本框**：预设照抄模板「页底一框」形态，未识别用户真实意图（按焦点块分框、
  左缘对齐、行数规则、上缘统一、下缘触灰边）——模板是手段，意图才是规格。
- **饱满排版**：w2/抛光均为手工摆放，无「递归切分+三类子块+间距层级」的排版代数；「满」
  只有目标没有可执行构造法，导致间距时宽时窄、块轮廓不饱满（用户点名的现有版本主要缺陷）。
- **逐页布局**：初版未按草稿的左中右/左右构图落位（如 p4/p5 左侧应为手绘内容块而非文章
  图）；p9 漏放 PRApplied 25 054054 的图（3 篇只落 2 图，占位图对应关系被丢）。
- **机制性保证缺口**：geometry 机械闸只管描边/互叠/越界，**无排版饱满度/对齐/间距判据**，
  审美规格全靠成员自觉——用户已明示「机械处理或规程化，由我决定」。

## 结论

1. Science 334 失败根因＝**Cloudflare JS 挑战**（非网络不稳、非机构权限），我们的
   Playwright 过 CF 能力在调用链上未生效；基础设施改进可打通（a2 给方案）。
2. PPT 差距根因＝预设提炼停留在「模板实测值」层，未升维到「用户意图规则」；且缺排版
   构造法与机械判据。改进方向：预设增补三机制（标题分散对齐公式/分焦点块引用框/递归
   切分饱满排版）+ 逐页布局规格入预设 + 机械判据扩充。
3. 两项均属可修面；具体方案见 A.a2。
