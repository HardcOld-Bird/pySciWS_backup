# A.a2 解决方案报告（tb-5 返工第 3 轮——一劳永逸修复设计）

## 解决方案

总目标：把「要求流转链」的五个漏点逐个焊死，使**要求写了就生效、状态变了就被抓、
报告说了就可验**。五件套（1–2 为骨干，3–5 为配套）：

### 1. Deck 规格书（spec）——要求的唯一真源

每 deck 一份机器可读 YAML（`data/大任务/5_开题PPT/deck-spec.yaml`），两类条目：
- **不变量**（重建不得破坏）：装饰层三层指纹（灰粗边框/白卡/半透明院徽——形状特征+尺寸+
  位置，从模板实测提取）、字体方案（标题/胶囊/正文的 latin+ea+panose 全参，照模板 rPr）、
  版式归属、动画规格指针；
- **变量槽位**（本轮要放对的东西）：每页每图槽＝{占位符指纹（草稿内嵌图 md5/尺寸）、
  内容锚（一句话+原文图号，如「RPP 86 Fig.7 场分布」）、来源文件、裁切参数}；引用框/
  胶囊/标题按预设公式引用（不重复抄参数）。
生成方式：组长+lit 从模板/草稿/图像索引**机械实测**汇编（现状断言全部带读数）。

### 2. `slides audit` 机械审计——断言对账器

`pysci-compose slides audit <deck> --spec <spec>`：逐项机械核验并输出 PASS/FAIL 表：
装饰层存在性与指纹、字体 runPr 含 `<a:ea>`、图槽数量/顺序/内容指纹（md5/尺寸/感知哈希）、
引用框规则、标题公式——能机械判的全机械判（内容同款判定用「占位符指纹比对+尺寸比对」，
判不了的降级为「人工确认」行但必须留勾选痕迹）。
**流程绑定**：每个生产叶交付必须附 audit 本页输出；rv 终检以 audit 全量输出为底稿；
「报告说了」必须有 audit 行支撑（根因 5 的对账器）。

### 3. 任务书 spec 切片生成 + 前言实证制（根因 1/2）

- 派单时按页/工序**从 spec 切片**生成任务书正文（槽位清单即工作清单），杜绝转写丢真；
- 任务书中凡涉「现在是什么状态」的断言**必须附机械读数**（md5/尺寸/形状清单截图式引用），
  禁止裸断言；组长书写时先跑读数（本轮 p10 案的教训固化为流程）；
- **索引去建议化**：图像索引只记事实（内容/尺寸/指纹/原文图号），「建议选 X/补充图 Y」
  类语句全部剥离；挑选决策规则唯一：占位符同款 > 原文图号匹配 > 其余（写入 spec 槽位），
  任何偏移必须在交付报告显式声明理由并经复核（建议不得再越权）。

### 4. 提取管线补缺（根因 4）

- fig 区检测上限可配（默认放开 6 上限）+ **按原文图号靶向提取**（figures.json 增
  figN↔原文图号映射；支持用户批注 bbox 直接落参）；
- 处理整页扫描型 PDF（NatMater 案）：检出"整页即图"模式并提示裁切参数；
- 对本轮已知缺图（RPP 86 Fig.7、PRL 123 Fig.2）重提并入索引。

### 5. 字体与装饰层工具化（根因 3）

- 写框工具/预设强制**字体全槽**（latin+ea+cs+panose 照模板 rPr 复制，python-pptx 的
  latin-only 坑用 XML 补写绕开），audit 机械校验每页标题/胶囊/正文 runPr；
- 重建脚本保留/复原装饰层（从模板页形状层复制三层），spec 登记 + audit 校验存在性。

### 实施与返工组织

- **a5（devops，本轮主战场）**：spec 载体与 schema、`slides audit`、任务书切片辅助、
  提取管线补缺、字体全槽工具——即上文 1–5 的机械面；
- **B 段（返工，次要但作为机制试金石）**：b_spec（组长+lit 汇编 deck-spec，实测生成）→
  w3–w10 每页一单**按 spec 槽位**修复（9+2 项批语 + 字体 + 背景 + 图序），每叶交付附
  audit 输出 → rv 终检（audit 全量 + 抽检）→ d_preset（本轮新规则入预设）→ b_last。

### 向用户汇报要点（按批语要求）

本方案属**中型工具建设**（spec schema + audit 工具 + 流程绑定），非推倒式大重构——
现有 deck/预设/队列体系全部沿用，新增的是「要求真源+对账器」一层。若实施中发现 audit
覆盖面需扩展到动画/几何全量（更大盘子），会在报告中再报。科学内容与版面美学判断仍由
人（用户）终审，机械面只保证「要求不丢、状态不骗」。

## 结论

五根因→五件套一一对应：spec（真源）+ audit（对账）+ 切片生成/索引去建议化（流转保真）+
提取补缺（能力边界）+ 字体/装饰工具化（不变量守护）。返工按 spec 驱动顺带完成，且作为
新机制的首次实战验证。待 A.a3 送审后实施。
