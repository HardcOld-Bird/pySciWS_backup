## 1. 目标排版几何规格

- 整图 **3 列**，每列 = 一组对照情形（左侧→右：①groove + gain ②groove, no gain ③gain, no groove）。
- 每列**自上而下 3 行**：
  - **行 1**：二合一极坐标雷达图（正方形）。同一极坐标系内**两条不同颜色的曲线轮廓**
    （L-incidence / R-incidence 各一条）。
  - **行 2**：半圆形声场色图（上半圆，平直直径边在下）。
  - **行 3**：半圆形声场色图（同规格）。
- **右侧 1 条共享 colorbar**，高度**恰好等于行 2 + 行 3**（不含行 1）。

实现建议（matplotlib）：

```python
# 3 行 × 4 列；第 4 列极窄，仅放共享 colorbar
gs = fig.add_gridspec(
    3, 4,
    width_ratios=[1, 1, 1, 0.05],     # 前三列等宽；colorbar 条 ~5% 宽
    height_ratios=[1, 1, 1],
    wspace=0.28, hspace=0.22,         # 行1↔行2 可略大（见 §5）
    left=0.05, right=0.93, top=0.95, bottom=0.06,
)
# 行1：雷达，set_aspect('equal') → 正方形
# 行2/行3：场图，set_aspect('equal')，xlim=(-r, r)，ylim=(0, r)，半圆上方朝上
# 共享 colorbar：不要用 fig.colorbar(ax=...) 自动吸附（会整高），
#   改用 fig.add_axes 按行2–行3 的垂直范围精确摆放：
cax = fig.add_axes([0.945, bottom23, 0.012, height23])   # 高度=行2+行3 的垂直跨度
fig.colorbar(im, cax=cax)
```

- 整图尺寸：双栏 APS 场景下 宽 ≈ 178–183 mm、高 ≈ 108–120 mm（w/h ≈ 1.5–1.65）。
  Ark 生成的参考图为 16:9（2816×1584），仅作气质参考，**实际按期刊双栏比例裁**。
- 三列的**垂直中轴必须对齐**；三列的雷达外径、两个半圆直径都取同一 `r`（同列同轴）。

## 2. 配色（具体色值 / colormap 名）

**场图发散配色（红-白-蓝）** —— 白必须落在 0 值：

- 首选色觉安全 colormap（Crameri 科学配色）：`vik`（或 `berlin`、`broc`）。
- 若只用 matplotlib 内置：`RdBu_r`。五档 hex（蓝→白→红）：
  `#053061` · `#4393c3` · `#f7f7f7` · `#d6604d` · `#67001f`
  （与参考图里「蓝白→砖红」的观感一致，白边干净、不过饱和，符合 APS 常态）。
- 关键参数：`vmin=-vmax`（**对称**）、`cmap` 居中于 0（`norm=TwoSlopeNorm(0, -vmax, vmax)`
  或直接对称 vmin/vmax），否则 0 不落白、场图观感立即变脏。

**两条曲线颜色（色觉安全对比对，Okabe–Ito 8 色板）**：

- L-incidence：`#0072B2`（蓝）
- R-incidence：`#D55E00`（朱橙红）
- （备选：蓝 `#0072B2` 对 品红 `#CC79A7`；避免用纯红绿对比。）

**其他**：

- 网格线：`#B3B3B3`；刻度数字与轴标签：`#222222`；面板边框/外弧：`#333333`。
- 背景纯白 `#FFFFFF`；不要灰底、不要渐变背景。

---

## 3. 字体与字号层级

- 字体族：`sans-serif`，优先 `Arial` / `Helvetica`，回退 `DejaVu Sans`。
- 字号（以整图宽 ~180 mm 计，7pt 基准）：

| 层级 | 用途 | 字号 |
|---|---|---|
| 面板/列标题 | case 名、(a)(b)… 或 L/R | **7 pt** |
| 轴标签 | 方位角、径向 r、`Re p₂ (Pa)` / `Far-field (a.u.)` | **7 pt** |
| 刻度数字 | 雷达角/径向、colorbar | **6 pt** |
| 注释小字 | Exp./Sim.、引线标签 | **6 pt** |

- 层级关系：标题 = 轴标签 > 刻度 > 注释小字；相邻层级字号差 ≥1 pt 才可辨。
- 单位用**正体**（`Pa`、`a.u.`），仅物理量符号（p₂、r）用斜体；避免全大写标题。
- **不要**整图大标题（旧图那行顶部长标题占行且易换行）；必要时把 case 名放列首。

---

## 4. 线宽与描边

- 雷达曲线 / 极坐标轮廓：**1.0–1.2 pt**，闭合、无标记点或极小点（`ms≤2`）。
- 网格线：**0.4–0.5 pt**，`alpha=0.6`。
- 坐标轴脊柱 / 半圆外弧：**0.6 pt**。
- 半圆「直径边」（平直底边）：单独一条直线，**0.8–1.0 pt**，`#333333`，
  两端**不要**刻度线溢出、不要小竖齿（旧图底边的小齿是缺陷），保持一条干净直线。
- 注释框 / 引线：框 **0.6 pt** 细线；引线细虚线 `linestyle=(0,(3,2))`，0.6 pt。

---

## 5. 留白与对齐

- 列内三行**共垂直中轴**、列内左右对齐。
- 列间白沟 ≈ 单面板宽的 20–25%（`wspace≈0.28`）。
- **行 1（雷达）与行 2 之间留白略大于行 2↔行 3**（给注释框 + 引线留位），
  可用 `hspace` 无法逐行控制时，改用子 `GridSpec` 或手动 `add_axes`。
- 顶部留白 ≥ 6 mm；左右外边距相等；第 3 列与 colorbar 之间留 **3–4 mm**。
- 半圆场图的**底边对齐**：三列行 2 底边在同一水平线，行 3 底边同理。

---

## 6. 共享 colorbar 排版要点

- **唯一一条**，位于最右；其 axes 高度 = 行 2 + 行 3 的垂直跨度（**不含行 1**）。
  用 `fig.add_axes([x, y, w, h])` 精确摆放（见 §1 代码）。
- 宽度 ≈ 整图宽的 **2–3%（约 4–5 mm）**；
- tick 朝**右外侧**（`cax.yaxis.set_ticks_position('right')`），
- 刻度**只取 5 档**：`[-vmax, -vmax/2, 0, +vmax/2, +vmax]`（手动 `set_ticks`），避免拥挤；
- **顶部/左上不得有浮动的 “±N” 端标**（旧图缺陷）——量程写进 tick 或标签即可；
- 不要 `extend` 三角（`extend='neither'`），保持直角端；
- 标签（如 `Re p₂ (Pa)`）旋转 270°、置于 colorbar 右侧，7 pt；
- colorbar 边框 0.6 pt `#333333`，刻度线朝外、长度 2–3 pt。

---

## 7. 注释元素（点缀，勿滥用）

- **菱形标注框**：可用，细线 0.6 pt、白色填充（`fc='white'`）、`ec='#666666'`；
  一个 panel 至多 1–2 个。
- **对照小图框（Exp./Sim.）**：如沿用旧图做法，尺寸 ≤ 场图直径的 **18%**，放 panel 角落，
  引线细虚线连到菱形框；不要遮挡中央波纹区。
- 小图框描边 0.6 pt；小图内部自身也有色条时**不要**再配独立 colorbar（共享一条即可）。
- 注释配色统一为 `#666666` 或与曲线一致的 Okabe–Ito 色，勿引入新色。

---

## 8. 旧图缺陷规避清单（逐条对照）

| 旧图缺陷 | 新版做法 |
|---|---|
| 左上角残留软件 logo | **不加**任何 logo / 水印 / 角标 |
| colorbar 顶部浮动 “±100/±5/±10” 端标 | **不画**浮动端标；量程进 tick/标签 |
| 极坐标/雷达刻度拥挤 | 角向每 45° 一标、径向仅 2–3 环，6 pt |
| 顶部长标题占行、可能换行 | 去掉整图长标题；case 名放列首（7 pt） |
| 场图 0 值不落白、色块发脏 | `vmin/vmax` 对称 + norm 居中 0 |
| 底边小竖齿/溢出刻度 | 直径边一条干净直线（§4） |
| 多列 colorbar 各一（旧图每行右侧一条） | **只留 1 条共享 colorbar** |

## 9. figure 可直接照抄的参数块

```python
import matplotlib as mpl

mpl.rcParams.update({
    "font.family": "sans-serif",
    "font.sans-serif": ["Arial", "Helvetica", "DejaVu Sans"],
    "font.size": 7, "axes.labelsize": 7, "axes.titlesize": 7,
    "xtick.labelsize": 6, "ytick.labelsize": 6,
    "axes.linewidth": 0.6, "grid.linewidth": 0.4, "grid.alpha": 0.6,
    "grid.color": "#B3B3B3", "lines.linewidth": 1.1,
    "text.color": "#222222", "axes.labelcolor": "#222222",
    "xtick.color": "#222222", "ytick.color": "#222222",
    "figure.facecolor": "white", "savefig.facecolor": "white",
    "pdf.fonttype": 42, "ps.fonttype": 42,           # 期刊矢量字体嵌入
    "savefig.dpi": 600,
})

CMAP = "RdBu_r"          # 首选改为 Crameri "vik"（色觉安全）
C_L, C_R = "#0072B2", "#D55E00"   # 两条雷达曲线（Okabe–Ito）
GRID, INK = "#B3B3B3", "#222222"
CBAR_TICKS = 5           # colorbar 仅 5 档
```

## 10. 一句话给 figure

> 三列(case) × 三行（行1 = 两色雷达，行2/行3 = 两个上下堆叠的半圆声场图），
> 右侧一条**只跨行 2–3** 的共享 colorbar；场图用对称 `RdBu_r`/`vik` 发散配色（0 落白），
> 曲线用 Okabe–Ito 蓝 `#0072B2` 对朱 `#D55E00`；全图 hairline（1.1/0.6/0.4 pt）、
> 7pt 基准字号、白底、均衡留白；去掉旧图的 logo、± 端标与拥挤刻度。
