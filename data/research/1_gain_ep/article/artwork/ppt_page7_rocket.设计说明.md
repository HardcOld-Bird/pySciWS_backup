# ppt_page7_rocket 设计说明

**用途**：汇报 PPT 页 7（末页）的整页单主题大图（16:9，2816×1584，一页全屏放这一张）。与页 4
（`ppt_page4_trend.png`）、页 5（`ppt_page5_topology.png`）成套：同一浅灰白底 + 深蓝 `#1F4E79` +
橙 `#D55E00` 两色系（色觉安全）、扁平矢量、极细线条、大留白、无 3D 与辉光。

## 视觉隐喻与图内文字对照

一支水平居中、垂直构图的**规整抽象几何火箭**（只用矩形/梯形/三角形等基本色块拼合，非写实插画），
把「本项目现状的反思」一眼说清——**科研产出只是顶部很小的一截有效载荷，自我维护基础设施才是庞大的
箭体与推进系统**：

| 图内元素 | 图内文字（逐字） | 隐喻含义 |
|---|---|---|
| 顶部小载荷：深蓝梯形鼻锥 + 浅橙矮舱体，高度仅约占火箭总高 1/8 | 「科研生产」「基础设施」（分两行） | 科研生产基础设施＝有效载荷：真正要交付出去、飞向目标的只有这一小块 |
| 巨大箭体：很高的深蓝圆角长矩形，占全图最大面积，白字全图最大字号 | 「自我维护」「基础设施」（分两行） | 自我维护基础设施＝箭体：为支撑上面那一小块载荷而必须背负的主体 |
| 箭体左右两个细长橙色助推器（无文字）、底部三个橙色梯形喷管 + 扁平三角形火焰 | 无 | 推进系统同属自我维护基础设施：起飞靠的是巨大的推力，而不是载荷本身 |
| 载荷／箭体分界处一条浅灰细虚线，向火箭左右各延伸一小段 | 无 | 纯几何地强调「上面小、下面大」的比例，不写任何数字 |
| 左上角大号深蓝标题 | 「现状反思」 | 点题：这是对现状的反思页 |
| 左下角浅灰小注（全图最小字号） | 「科研产出是小载荷，自我维护是巨大的推进系统」 | 一句白话题眼，面向非专业听众 |

图内文字白名单仅上述四条（「科研生产基础设施」在舱体内分两行、「自我维护基础设施」在箭体内分两行），
**无任何其它文字、英文、数字**，避免投影错字与伪码字形。

## 规格与配方

- 尺寸 2816×1584（精确 16:9）；模型 `doubao-seedream-5-0-pro-260628`（即梦 5.0 Pro）文生图；
  prompt 全文见 `runs/ppt_p7_{a,b,c}.json`，并已内嵌交付 PNG 的 `pysci:prompt` / `pysci:model` /
  `pysci:backend`（5.0 档只出 jpeg，故经 `imagine adjust` 免费转 PNG 后手工补内嵌溯源）。
- **计费 3 张**（候选 A/B/C，均归档于 `data/skills/ai_drawing/gallery/ppt_p7_{a,b,c}.jpg`）；
  交付首选 **B**：
  - A：文字与几何全对，但火箭细窄、页面左右留白过大，载荷占比偏大（约 1/5），投影冲击力弱；
  - **B**：载荷占比最小（约 1/8）、箭体白字最大、纵向占满页面——隐喻对比最强，故交付；
  - C：为把火焰收敛成简单三角形而重发，结果鼻锥变长使载荷占比反而升到约 1/5，且箭体上缘被画成
    斜切肩形（不够「规整矩形箭体」），故仅归档不交付。
- 交付物 `ppt_page7_rocket.png`（由 B 转格式而来），B 的源图留存于 `assets/ppt_p7_b.jpg`。
