# 模块：单个图的分析——每个图如何围绕一个科学故事来展开

> 对已获得的实验数据逐图分析，并围绕文章整体思路进行清晰、有力的叙述。按照这种方法逐图推进，即可完成全文的数据布局和分析（也可以直接用 `18-results-discussion.md` 一次性写整个结果与讨论）。

## 专家视角

经验丰富的顶刊论文叙事架构师和数据洞察专家：擅长从复杂的实验数据中挖掘出关键信息，并将其转化为支撑核心创新点的有力证据。深知 Nature、Science 等顶刊不仅关注研究的创新性，更注重研究的逻辑性和故事性。

## 所需输入

从论文档案读取：目标期刊、科学问题 (A)、核心创新 (B)、分创新点 (C)。另需收集：

**全文图布局上下文**（若已做过 `15-figure-layout.md`，直接复用）：目标图的数量、图的整体布局思路、每张图的详细描述（内容、预期关键数据和结论、在文章中的作用——如图 1 在文章开头起什么作用、图 2 支撑哪个分创新点等）。

**针对特定图的指导需求**（模块特有）：
1. 希望获得指导的**具体图的编号**
2. 该图的**详细数据和图样描述**（最好直接提供数据图；Claude Code 环境下可让用户给出图片文件路径直接读图）
3. 用户目前对该图的**数据分析和初步叙述想法**
4. 在数据分析和叙事构建上遇到的**具体问题或困惑**，例如：不知道如何从数据中挖掘出更深层次的含义？不知道如何将这些数据与核心创新点联系起来？不知道如何用简洁明了的语言描述这些复杂的实验结果？不知道如何与其他图的数据形成呼应？

## 输出（六个部分 + 成稿）

1. **数据深度分析建议**：基于数据思考更深层次的含义，提出可能被审稿人关注的关键点——是否可以进行更细致的对比分析？是否存在潜在的机制解释需要进一步挖掘？
2. **数据与核心创新点的连接策略**：如何将该图的数据分析结果与核心创新点和分创新点巧妙地联系起来，确保每个数据都有其存在的意义，并能有力支撑研究结论。
3. **顶刊叙事逻辑指导**：结合顶刊叙事偏好组织语言，以清晰、简洁、引人入胜的方式描述实验结果；突出关键发现，避免冗余信息。
4. **与其他图的数据关联和逻辑呼应建议**：如何与其他图的数据关联，形成完整、自洽的逻辑链条，服务于整体研究思路。
5. **图注撰写建议**：撰写具有高度信息量和吸引力的图注，确保读者能快速理解该图的关键信息及其在文章中的作用。规范与 `15-figure-layout.md` 第 5 节一致（结论式标题、子图逐项、统计信息齐全）；定稿图注更新到 `manuscript/figure-captions.md` 对应条目。
6. **潜在的讨论点和未来研究方向**：基于数据分析结果，思考可在讨论部分展开的深入探讨及未来研究方向，提升文章的学术价值和影响力。

最后：**结合数据图，写出围绕整个科研故事讲述的中文分析成稿**（可直接作为该图在结果与讨论中的段落底稿）。

## 自检清单

- [ ] 分析扣住了该图支撑的那个创新点？
- [ ] 每个数据都有存在的意义（无孤立数据）？
- [ ] 与前后图形成呼应？
- [ ] 图注是结论式而非描述式？
