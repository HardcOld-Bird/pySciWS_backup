# 模块：文献检索、查新与引用插入

> 写作与找文献分离：正文写作阶段专注逻辑，引用处一律留 `[REF: ...]` 占位符；全文完成后由本模块全网检索、核证、按目标期刊格式统一插入。本模块同时承担创新点查新。

## ⛔ 真实性红线（凌驾于一切之上）

- **每一条写入稿件的文献必须核证后才能插入**：通过 Crossref API（`https://api.crossref.org/works?query.bibliographic=<标题关键词>` 可靠返回卷号/DOI）、期刊官网或出版社页面验证标题、作者、年份、卷期页码、DOI 全部真实存在且相互匹配。
- **严禁编造或"凭印象补全"任何 DOI、卷期页码。** 一条幻觉引用足以触发学术诚信审查。
- 检索不到合适文献、或细节无法核证时：**保留占位符原样**，在交付说明中明确列出"未能解决的占位符"清单，交还用户自行补充。宁缺毋假。

## 功能一：创新点查新（供 02 模块调用）

**时机**：候选核心创新写入论文档案之前，必须先查新。

流程：
1. 把候选核心创新拆成 2-3 组检索式（策略关键词 × 体系关键词 × 领域词，中英文各查）。
2. 用 WebSearch 检索近 5 年文献（重点顶刊 + 预印本平台 arXiv/ChemRxiv/bioRxiv——预印本也算被占坑）。
3. 输出**查新报告**：
   - 结论三选一：✅ 未见报道（可作为核心创新）/ ⚠️ 有相近工作但存在差异化空间（列出差异点，建议调整创新表述以凸显差异）/ ❌ 已被报道（回到 02 模块换方向）。
   - 最接近的 3-5 篇竞争文献（核证后的完整引用），并说明各自与用户想法的异同——这批文献同时存入档案"关键文献库"，日后 R&D 对比和引言都会用到。

## 功能二：批量文献插入（主功能）

**时机**：正文各部分（引言、R&D 等）中文定稿之后、一致性终检之前。

### 占位符规范（写作模块统一使用）

```
[REF: 主题描述｜类型]
类型三选一：经典奠基 / 最新进展 / 竞争工作
示例：[REF: 水电解制氢的意义｜经典奠基]
      [REF: 磁场调控OER的近期报道｜最新进展]
      [REF: LiCoO2重构路径调控｜竞争工作]
```

### 流程

1. **扫描**：通读成稿（或 `manuscript/` 目录下各文件），提取全部 `[REF: ...]` 占位符，列成任务清单。
2. **逐个检索**：按占位符的主题+类型全网检索，选择标准：
   - **经典奠基**：该论断的原始出处或领域公认的高被引奠基文献，宁可老而重，不用新而轻。
   - **最新进展**：近 2-3 年顶刊为主，体现作者跟得上前沿。
   - **竞争工作**：与本文直接可比的代表性工作，供 R&D 对比（引用要"手下留情"，客观陈述其贡献再指出未覆盖之处）。
   - 同一处一般 1-3 篇；全文引用结构符合手册原则——**经典、重要、有分量的文献优先**；适当纳入用户自己的前期工作（问用户要清单），体现其领域地位。
3. **核证**：每条候选过 Crossref/官网核证（见红线）。
4. **插入**：按论文档案"期刊画像"中的参考文献格式（数字上标/作者-年份等）替换占位符，并生成文末参考文献列表（格式同画像；无画像则默认数字顺序制并提示先跑 `04-journal-selection.md`）。
5. **交付映射表**：输出"占位符 → 所选文献（含 DOI）→ 选择理由"三列映射表，以及"未能解决的占位符"清单。提醒用户：**每篇插入的文献都需要自己读过摘要确认相关性，最终责任在作者。**

## 功能三：引用质量体检（可选）

对用户已有的参考文献列表做体检：占位是否全消？经典/最新配比是否合理（引言前段偏经典、后段偏近 3 年）？是否过度自引（一般 <15-20%）？是否遗漏了必然被审稿人想到的关键竞争工作？有无引用掠夺性期刊？

## 功能四：审稿人情报（供 cover letter 使用）

利用本模块建立的**关键文献库**反推建议审稿人——被你正面引用的近期工作的通讯作者，是最合理的候选（懂行、非直接竞争、看到自己被引用心情不错）。

**输出两份名单：**

1. **建议审稿人 3-5 位**，每位给：姓名 / 机构 / 研究方向 / 推荐理由（"本文引用并正面讨论了其 20XX 年 XX 工作，方向高度相关且无直接竞争"）。候选优先级：被引的方法/表征来源作者 > 同方向但不同体系的作者 > 领域综述作者。
2. **建议回避名单**：竞争工作的作者（正在做同一策略的组）、近 3 年合作者与共同发文人、同机构人员、有公开学术分歧者。

**边界与提醒**：邮箱、现任职机构和近期动向需用户自行核实（人员流动快）；最终推荐谁由通讯作者拍板；部分期刊要求审稿人来自不同国家/地区，按期刊画像核对。成果交给 sci-cover-letter 技能写入投稿信的推荐审稿人部分。

- [ ] 引用格式与期刊画像一致？
- [ ] 映射表（占位符→文献→理由）已交付？
