# 模块：材料和方法（Methods / Materials and Methods）写作

> 顶刊主刊 M&M 的写作精髓：极致简洁、直击核心、突出创新，同时确保所有必要细节在补充材料 (SI) 中完整呈现以保证可重复性。

## 专家视角

深谙 Nature、Science 等顶刊发表规范的资深编辑和写作专家。

## 所需输入

从论文档案读取：目标期刊、科学问题 (A)、核心创新 (B)、分创新点 (C)（提供上下文）。另需用户提供两层信息：

**第一层：识别并明确指出 M&M 中的【核心与新颖】部分**
- 【新颖方法/关键改进】：本研究中独创的、首次使用的、或对标准方法进行了关键性重大改进的实验方法或技术。（这是 M&M 主体描述的重点）
- 【核心材料/试剂】：哪些材料或试剂是非标、自行合成、或对研究结果有决定性影响的。（常规、易购的标准试剂通常省略）
- 【关键参数/条件】：哪些实验参数或条件是非标准的、本研究优化的、或直接影响核心结论验证的。（标准仪器的常规参数设置通常省略）
- 【关键对照实验设计】：对于理解核心创新至关重要的特殊对照组设计（若有）。

**第二层：需要完整细节支撑的【全部】M&M 信息（供筛选和放入 SI）**
所有试剂的纯度/来源/货号、所有仪器的型号/厂家、所有步骤的详细参数等。需要这些完整信息才能判断哪些是"常规"应省略的、哪些是"核心/新颖"应在主文提及的、哪些需在 SI 中详述。

## 写作范式（顶刊风格要求）

1. **高度凝练，聚焦核心**：只包含对理解本文核心创新策略 (B)、关键结果和主要结论所**绝对必需**的方法学信息。篇幅极其简短。
2. **突出新颖性**：重点、清晰地描述【新颖方法/关键改进】；对这些新颖之处提供足够的关键细节，以便读者理解其原理和操作。
3. **省略常规信息**：
   - 常规试剂：不列出标准、易购化学试剂的来源、纯度、货号（除非该试剂本身是研究的关键变量或非标品）。
   - 标准方法：领域内公认的标准实验步骤（常规离心、洗涤、干燥）或表征技术（标准 SEM、XRD、UV-Vis 测试），仅提及方法名称即可，不详述具体步骤或仪器型号/参数。必要时通过引用经典文献或 SI 提供细节，例如 "as previously described [ref]" 或 "Details can be found in the Supplementary Information"。
   - 标准仪器：不列出常规、标准仪器的具体型号和生产厂家，除非该仪器本身具有特殊性或其特定高级功能是研究的核心。
4. **关键信息点到即止**：必须提及的【核心材料/试剂】或【关键参数/条件】仅作简要陈述，提供理解研究所需的最小信息集。
5. **结构简洁**：采用简短段落或要点形式，按逻辑分组（如 Sample Preparation, Measurements, Data Analysis），避免过多层级和冗长描述。
6. **明确指向 SI**：在 M&M 的开头或结尾、或在提及标准方法处，明确说明 "Detailed materials and methods are available in the Supplementary Information."
7. **语言风格**：极其简洁、精确、客观；使用过去时态。

## 输出

1. 主刊 M&M：高度浓缩、符合 Nature/Science 主刊风格的"材料与方法"文本（默认先中文稿，按需出英文），只含最核心和新颖的方法学信息，并明确提示读者查阅 SI。成稿写入 `manuscript/19-methods.md`。
2. SI 归档清单：列出哪些细节应放入 Supplementary Information（基于用户提供的第二层完整信息做常规/核心分拣）。**清单不是终点**——接着用 `27-si-writing.md` 模块把清单写成完整、可复现的 SI 文稿。

## 自检清单

- [ ] 主文只保留了新颖方法与关键参数？常规试剂/方法/仪器都已剔除或指向 SI？
- [ ] 有指向 SI 的标准语句？
- [ ] 过去时态、客观、无冗长层级？
- [ ] 新颖方法的细节足以让读者理解原理和操作？
