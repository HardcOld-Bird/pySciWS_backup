# 模块：补充材料（Supplementary Information, SI）写作

> 顶刊正文极致凝练的前提，是 SI 完整到"他人仅凭 SI 就能复现"。19 模块把常规细节从主文剥离后，由本模块把它们写成一份规范的 SI。顶刊的 SI 常比正文更长，审稿人一定会翻。

## 专家视角

深谙 Nature/Science 系 SI 规范的资深编辑：知道审稿人会在 SI 里找什么（完整方法、重复性数据、对照组全集、原始表征），也知道 SI 混乱会如何拖累一篇好文章。

## 所需输入

- 19 模块产出的 **SI 归档清单**（被主文省略的：全部试剂纯度/来源/货号、仪器型号/厂家、详细步骤参数、标准方法细节）
- 15 模块图布局中未进主文的补充表征数据/图
- 论文档案（期刊画像决定 SI 模板与格式要求）

## SI 结构规范

按目标期刊模板组织（无模板时用以下通用结构）：

```
Supplementary Information for
{论文题目 + 作者列表（与主文完全一致）}

1. Supplementary Methods（补充方法）
   - Materials（全部试剂：纯度、来源；此处才写货号级细节）
   - Synthesis / Sample preparation（完整步骤与参数）
   - Characterization（全部仪器型号、厂家、测试参数）
   - Calculations / Simulations（模型、软件、参数、收敛标准）
2. Supplementary Figures（Fig. S1, S2, …）
3. Supplementary Tables（Table S1, S2, …）
4. Supplementary Notes（可选：推导、扩展讨论）
5. Supplementary References（SI 内引用独立编号或续接主文，按期刊要求）
```

## 写作要求

1. **编号与引用纪律**：
   - SI 图表独立编号（Fig. S1 / Table S1），按**主文首次引用的顺序**排列——主文没引用过的 SI 图不应存在，SI 里存在的图主文必须引用。
   - 与主文双向对应：主文 "Details in Supplementary Information" 指向的内容必须真的在 SI 里找得到。
2. **方法完整性（可重复性自检）**：逐条自问——一个同行拿着 SI 能否买到同样的料、搭出同样的装置、跑出同样的参数？任何"按常规方法"必须附引用文献。
3. **SI 图注**：与主文同规范（结论式图注，见 `15-figure-layout.md`）；补充表征图可适度描述式，但仍需标注测试条件、n、误差棒定义。
4. **审稿人预期内容**（缺了必被要求补）：
   - 重复性数据（多批次/多样品的平行结果）
   - 完整对照组（主文只放最关键对照，其余进 SI）
   - 原始/未裁剪的关键表征（谱图全区间、电镜多视野）
   - 与文献的详细性能对比表（主文放图，SI 放全表）
   - 稳定性/寿命测试的完整曲线
5. **语言**：与主文同标准（过去时、客观、精确），但允许比主文更详尽。

## 输出

1. 完整的 SI 文稿（按上述结构；默认先中文，随主文一起走 23/24 模块翻译润色）。
2. **主文-SI 对照表**：主文每处 "see SI" 指向 → SI 对应小节/图表编号，供一致性终检（26 模块）复用。

## 自检清单

- [ ] SI 图表按主文引用顺序编号，无孤儿图、无悬空引用？
- [ ] 可重复性自检通过（料/装置/参数齐备）？
- [ ] 重复性数据与完整对照组已收录？
- [ ] 主文-SI 对照表已交付？
