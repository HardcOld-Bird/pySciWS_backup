# 模块：数据出图——从原始数据到出版级图表

> 把 15/22 模块的"文字规范"变成可执行产出：用户给数据文件，直接产出符合期刊规格的成图 + 可继续调整的绘图脚本。定位是**高质量底稿**——用户可拿脚本继续手调，不替代 Origin/Illustrator 的最终精修。

## 所需输入

- **数据文件**：CSV / Excel / 文本（让用户给文件路径，直接读取；说清楚每列含义）
- **要传达的结论**：这张图要证明什么（对应 15 模块图布局中该图的叙事作用）
- 从论文档案读取：期刊画像（栏宽规格）、该图在图清单中的编号与图注

## 流程

1. **读数据、确认图型**：根据数据结构和结论建议图型（对比→柱状/散点；趋势→折线；分布→箱线；构效关系→散点+拟合；性能对标→散点大图。图型服务结论，不炫技）。
2. **生成 matplotlib 脚本**：
   - 脚本第一行强制加载技能自带样式：`plt.style.use(r"<技能目录>/assets/journal.mplstyle")`（找不到样式文件时把其中参数内联进脚本）。
   - 图宽按期刊画像栏宽换算：单栏 89 mm ≈ 3.5 in、双栏 183 mm ≈ 7.2 in（无画像默认单栏）；高度按黄金比例或数据需要。
3. **渲染输出**：同时导出 `PNG（300 dpi，预览用）` + `PDF 或 SVG（矢量，投稿/精修用）`，脚本与成图存入 `manuscript/figures/`（如 `fig2_polarization.py` / `.png` / `.pdf`）。
4. **交付**：成图路径 + 脚本路径 + "可调参数速查"（改颜色/字号/图例位置对应改哪一行）。

## 内置规范（与 15 模块红线一致，脚本中强制落实）

- **误差棒**：有重复数据必须画误差棒，图注写明定义（SD/SEM/95% CI）与 n；只测一次的数据不画。
- **显著性标注**：涉及组间比较时按用户提供的检验结果标注（*p < 0.05 等）。
- **配色**：Okabe-Ito 色盲安全调色板（样式文件已内置 prop_cycle）；对照组用中性灰；语义色一致（同一样品全文同色）。
- **去 chartjunk**：无顶部/右侧边框、无背景网格（必要时极淡）、图例无框、不用 3D 效果。
- **字号**：最终版面尺寸下 5-7 pt 可读（样式文件已设 7 pt 基准）。
- **标签**：轴标签含物理量与单位（如 `Overpotential (mV)`）；出版图一律英文标签（也避免中文字体缺失问题）。

## 环境处理

- 先 `python -c "import matplotlib"` 检查；缺则 `pip install matplotlib`（pandas 同理，读 Excel 需 openpyxl）。
- 渲染失败时降级：输出完整脚本 + 参数说明，让用户在本地/服务器运行。

## 与其他模块的关系

- 图型选择和叙事作用来自 `15-figure-layout.md` 的图布局方案；
- 图注文本来自 `manuscript/figure-captions.md`（本模块只负责图形本体）；
- 已有成图只想改配色 → 走 `22-figure-colors.md`；
- 概念/机理示意图（Figure 1 类）不适合 matplotlib，走 `21-graphical-abstract.md` 的方案描述 + 专业绘图。
