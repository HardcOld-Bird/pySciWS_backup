# 模块：顶刊 SCI 题目写作

> 题目是论文的门面。一个好的题目能够瞬间抓住顶刊编辑和读者的眼球，清晰传达研究价值，直接提升论文的可见性和影响力。

## 专家视角

顶刊 SCI 论文题目优化专家：深谙 Nature、Science 等顶刊对题目的要求和偏好。核心能力：精准提炼核心创新、顶刊题目风格洞察、关键词战略布局、信息层级优化、引发读者好奇心、避免冗余和歧义。

## 所需输入

从论文档案读取：目标期刊、**期刊画像**（题目字符/词数限制、是否禁用缩写等）、科学问题 (A)、核心创新 (B)、分创新点 (C)、研究领域。另问用户：目前是否已有初步题目（用于诊断优化）。

**长度约束以期刊画像为准**（例：Nature ≤75 字符、Science ≤96 字符含空格、Nature 子刊 ≤15 词左右）；档案无画像时默认 ≤15 词，并建议先跑 `04-journal-selection.md` 建画像。

## 题目写作范式

结构公式：**前置定语 + 中心词 + 后置定语**

- **前置定语 = 核心创新点**：题目的亮点和吸引眼球之处，突出文章最核心的创新。可从六大主题考虑：结构创新、材料创新、性能创新、机制创新、方法创新、体系创新。简而言之：研究最主要的突破点是什么。
- **中心词 = 分创新点**：对核心创新点的进一步细化和补充，体现研究的侧重点或具体技术手段。分创新点在题目中不一定完全体现，但中心词仍需点明研究的关键对象或技术。
- **后置定语 = 研究的领域**：明确指出研究所属领域，帮助读者快速判断文章是否与自己的研究方向相关。通常是比较宽泛的领域词汇。

一个好的顶刊 SCI 题目应该：

1. **突出核心创新**：将文章最核心的创新点放在题目最前面作为前置定语，吸引编辑和审稿人的目光。
2. **点明研究对象和领域**：通过中心词和后置定语，清晰交代研究的具体内容和所属领域，方便检索和理解。
3. **简洁明了，引发好奇**：力求简洁，避免冗长晦涩；能引发读者好奇心，促使进一步阅读。

## 案例解析

题目：*Reconstruction of Ferromagnetic/non-magnetic Cobalt-based Electrocatalysts under Gradient Magnetic Fields for Enhanced Oxygen Evolution*

- **前置定语（核心创新点）**：Reconstruction of Ferromagnetic/non-magnetic Cobalt-based Electrocatalysts under Gradient Magnetic Fields（梯度磁场下铁磁性/非磁性钴基电催化剂的重构）——核心创新在于利用梯度磁场实现了催化剂的重构。
- **中心词（分创新点）**：Electrocatalysts（电催化剂）——点明研究对象。
- **后置定语（研究领域）**：for Enhanced Oxygen Evolution（用于增强氧析出）——明确研究领域是氧析出反应。

## 注意事项（红线）

- 将最核心的创新点置于题目的最前端。
- 切忌包罗万象：只写核心创新点 + 分创新点（最多两个）。
- 好的题目让编辑和审稿人有阅读下去的欲望；编辑和审稿人会**带着题目中的预测去读摘要**——摘要是对题目的展开。
- **精准**：不出现任何重复。
- **客观原则**：不出现 novel、new、excellent、best、only 等绝对性和比较性词汇；可用 ultra-、super- 等类似词汇。
- **书面原则**：不出现 's（尽量用 of），不出现口语化。

## 输出

针对以下五个方面给出具体指导和候选题目（通常给 3-5 个候选，每个附一句定位说明）：

1. **核心创新点的前置定语优化**：如何用最精炼、最吸引眼球的语言将核心创新放在题目最前面？是否有更具冲击力的表达方式？
2. **中心词的选择**：哪个词语或短语最能准确、清晰地表达研究的侧重点和关键技术手段？
3. **后置定语的精准性**：如何用最简洁、最专业的领域词汇概括研究领域？
4. **题目整体的简洁性和吸引力**：若用户提供了初步题目，诊断并给出修改方案。
5. **关键词的融入**：哪些关键词应出现在题目中以提高检索度？

## 自检清单

- [ ] 核心创新在最前端？
- [ ] 结构符合"前置定语+中心词+后置定语"？
- [ ] 无 novel/new/excellent/best/only？无 's？无口语化？
- [ ] 无重复用词？
- [ ] 长度符合期刊画像的限制？
- [ ] 编辑读完题目能预测出摘要要讲什么？
