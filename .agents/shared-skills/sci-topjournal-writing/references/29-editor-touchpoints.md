# 模块：编辑触点文案包（按期刊画像选配）

> 投稿系统里真正塞到编辑与读者眼前的，除了 cover letter 还有一串 30-120 词的"微文案"。它们比摘要更通俗、比题目信息量大，写作难度极高，且**各刊要求不同——只生成目标期刊画像中标记"需要"的项目 + 用户主动点名的项目**，不做无用功。

## 专家视角

顶刊编辑部的文案把关人：知道编辑扫一眼 eTOC 就决定推荐位、记者只读 significance statement 就写报道。

## 所需输入

全部来自论文档案：三要素（A/B/C）、关键定量数据、研究意义、**期刊画像的"编辑触点要求"字段**（缺失时先跑 `04-journal-selection.md` 补齐，或按用户点名的项目生成）。

## 项目清单与规范

| 项目 | 典型期刊 | 规格 | 写法要点 |
|---|---|---|---|
| One-sentence summary | Science | 一句话（约 ≤125 字符量级） | 主谓宾完整的陈述句，说清"发现了什么+意味着什么"；不留悬念、不用行话 |
| eTOC blurb | Cell 系（Cell/Joule/Chem/Matter） | ~50 词，第三人称（"Zhang et al. show that…"） | 面向翻目录的科学家：一句背景+一句发现+一句意义；比摘要口语化一档 |
| Significance Statement | PNAS 等 | ~120 词 | 面向**跨领域科学家**：为什么这个问题重要（2 句）→ 我们发现了什么（2 句）→ 改变了什么（1-2 句）；严禁子领域行话 |
| Context & Scale | Joule / Chem | 150-200 词 | 把工作放进能源/社会尺度的大图景：宏观挑战→本工作的位置→对更大目标的推进 |
| 通俗导读 / Press release 素材 | 各刊接收后备用（可选） | 150-250 词 | 面向记者与公众：类比开场、零公式零缩写、落点在"对普通人意味着什么" |

## 写法共性（五条铁律）

1. **通俗度阶梯**：题目 < 摘要 < 触点文案——每降一级砍掉一半行话。写完自测：非本领域的博士生能否一遍读懂？
2. **只留最强的一个数据**：多个数字会互相稀释；选最能打的那个（或干脆不用数字，用"提升一个数量级"式表述）。
3. **落点在改变**：结尾必须回答"这改变了什么认知/能让什么成为可能"，而不是"我们做了什么"。
4. **动词强度守全局红线第 8 条**：通俗化不等于可以过度宣称——suggest 的证据在这里也不能写成 prove。
5. **与摘要不重复**：触点文案不是摘要的压缩版，是**换受众重讲一遍故事**。

## 输出

按画像要求逐项生成（英文为主，附中文对照），每项标注字数/字符数证明合规；汇总写入 `manuscript/29-editor-touchpoints.md`。若画像显示目标期刊一项都不要求，明确告知用户并询问是否仍要备一份通俗导读（转投或宣传时会用上）。

## 自检清单

- [ ] 只生成了画像要求 + 用户点名的项目？
- [ ] 每项符合字数/人称/受众规格？
- [ ] 无行话？落点在"改变了什么"？
- [ ] 数据 ≤1 个且与档案一致？动词强度不超证据等级？
