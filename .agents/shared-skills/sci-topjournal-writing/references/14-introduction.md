# 模块：引言写作——漏斗式 3-5 步下楼梯模型

> 引言是论文的灵魂，决定读者是否愿意深入了解研究。其精髓在于构建一场逻辑严谨、引人入胜的智力旅行：将宏大的领域背景通过数次"起承转合"的精妙转折层层聚焦，最终让读者在"山穷水尽"之处，对即将揭晓的"柳暗花明"（本文的核心创新）充满期待与信服。

## 专家视角

顶刊 SCI 论文引言写作的资深战略家和叙事大师：宏观视野与精准定位、科学问题凝练大师、创新点巧妙铺垫、顶刊叙事逻辑专家、参考文献的战略性运用、激发读者兴趣。

## 所需输入

从论文档案读取：目标期刊、科学问题 (A)、核心创新 (B)、分创新点 (C)、关键定量数据（摘要可直接作为输入）。

## 引言写作范式："下楼梯"模型

**理念核心**：引言的终极目标是构建**逻辑的必然性**。让读者清晰地理解：为什么这个领域重要（起），大家已经做到了哪一步（承），但还存在什么越来越具体的致命问题（转），最终顺理成章地引出本文的解决方案（合）。

构建一个包含 3-5 个逻辑层级（"楼梯台阶"）的引言，每一个层级都是一轮独立的"起-承-转-合"：

**第一段（第一层楼梯——大领域）**
- 起/承：从宏观领域背景入手，介绍其重要性和当前主流技术。
- 转：指出该领域的宏观技术瓶颈或根本性挑战。
- 合：提出解决该瓶颈的总体方向或必要性。

**第二/三段（第二、三层楼梯——聚焦方向）**
- 起/承：聚焦到上述"总体方向"内的具体研究领域，回顾该方向的代表性进展。
- 转：在上一层问题的基础上，进一步收敛和深化，指出当前主流方法中一个更具体、更深入的科学问题或局限性。
- 合：提出解决这个新问题的可能策略或研究思路。

**（可选）更多层楼梯**：以前一层提出的"策略"为新起点，继续进行"起承转合"，直到问题被剥离至**"最后一公里"**，为引出本文的"独门绝技"做好最终铺垫。

**最后一段（楼梯底部——本文方案）**
- 转/合：利落地引出本文的核心创新策略 (B)，清晰阐述它如何精准解决最后一层楼梯提出的那个终极难题。
- 合：简要概括本文的主要工作、分创新点 (C1, C2) 和最终取得的关键成果，点明研究的重大意义和贡献。

## 起承转合的结构规律

- 起 = 背景；承 = 研究现状（有时并不出现）；转 = 存在的问题；合 = 我们要做的事儿。
- 起承转合在 introduction 一般 3-4 次。
- 起、承二者可以合并，或者出现一个即可。
- 转、合一般在每次循环中都会出现。
- **每一次"转"是在上一次"转"的基础上更深，更加接近科学问题。**
- "合"也是更加聚焦我们最后提出的"一招鲜"策略。
- 最后一段（本文概况）用**预测的语调**，包括核心创新点、分创新点和本文的核心数据。

## 完整案例参考（学习其层层递进的写法）

- **起**：水电解已被广泛认可为一种有前景的绿色氢气获取途径。
- **转**：然而，由于氧析出反应 (OER) 涉及复杂的四电子转移过程，阳极反应的动力学缓慢极大地限制了整体电解效率。
- **合**：因此，开发高效的电催化剂以促进 OER 动力学并尽量减少能量损失变得至关重要。
- **起承**：目前，许多过渡金属催化剂已被开发用于高效的 OER 催化，如氧化物、磷化物、硫化物、钙钛矿和金属有机框架等。这些材料在碱性 OER 过程中往往会经历表面重构，包括相变、形貌和组成的变化，形成了对 OER 具有实际活性的金属氧化物或(氢)氧化物。
- **转**：然而，催化剂的重构并不总是对催化活性有利。
- **合**：因此，合理操控表面重构以获得更多高活性的催化位点对于增强 OER 性能至关重要。
- **起承**：最近，Lim 等人报道了一种通过阳离子氧化还原调控策略重新引导层状 LiCoO₂ 氧化物的重构路径，通过精确调控催化剂的重构成功获得了优越的 OER 电催化剂。
- **转**：尽管在催化剂的定向表面重构方面取得了显著进展，但仍缺乏简单有效的方法来实现这一目标。
- **合**：外部磁场辅助策略是提高 OER 固有活性的潜在方法。
- **起**：作为一种非接触且非破坏性的媒介，磁场被认为是调控 OER 性能的有前景工具。
- **承**：磁场对 OER 的潜在影响包括磁流体力学、磁热效应、自旋极化、自旋态重构等。
- **转**：此前，磁场对 OER 活性的显著影响集中在稳定或已重构的催化剂上，而对于催化剂的表面重构过程，理论和实验研究仍然不足。
- **合**：然而，众所周知，梯度磁场可以对周围的顺磁性物种（如自由基、顺磁性阳离子和具有未配对自旋的分子）施加 Kelvin 力，驱动它们朝向更高磁场密度的区域移动。因此，值得探讨的是，重构过程中生成的顺磁性物种是否可以通过梯度磁场定向操控，以选择性调控活性物种。
- **核心创新点**：在这项工作中，我们采用 CoFe₂O₄（简称 CFO）作为核，1,4-苯二甲酸根（BDC）作为壳，构建了铁磁性/非磁性 CFO@CoBDC 核壳前驱体，并研究了梯度磁场在表面重构过程中的影响。
- **分创新点+主要数据**：铁磁性 CFO 在外加磁场下能够生成局部梯度磁场。选择 CoBDC 是因为它在碱性条件下易于转化为钴氧氢氧化物（CoOₓHy）。我们证明了梯度磁场诱导的 Kelvin 力能够定向调控 CoBDC 的表面重构，形成更多的二价钴（Co²⁺）活性位点，从而显著提高氧析出反应（OER）性能，电流密度提升约 128%，过电位降低 28 mV。此外，在移除外部磁场后，催化活性可以持续超过 100 小时。

## 注意事项（红线）

- 逻辑需要有波峰和波谷。
- **不是科普**——让人读起来有收获，要有自己总结的点。数据、证据、细节为上，切忌做科普：编辑和审稿人段位更高。
- 用最少的语言，描述最明白的事儿。
- **转、合是重点**，一定善用连接词（However, Therefore, Nevertheless, Thus…），让编辑和审稿人注意到。转合 = 对科学问题本质的认识 + 创新点。
- 起、承做到简约而不简单。
- 背景和科学问题的提出过程中，一定要选用**经典、重要和有分量的文献**。
- 关于自己在本领域的贡献，可以适当说明，让编辑和审稿人明白自己在本领域的地位和价值。
- **手下留情**——尤其是论述前人的工作缺乏创新时。

## 输出（两步交付）

1. **逻辑路径规划**：先为引言规划出 3-5 个"下楼梯"的步骤。简要说明每一层的"起承转合"分别是什么，重点阐述每一层"转"（问题）是如何在前一层基础上进行聚焦和深化的。**先给用户确认路径，再动笔。**
2. **引言全文撰写**：基于确认的逻辑路径，撰写逻辑流畅、层层递进的完整引言。按手册工作流默认先出中文稿。
3. **文献占位纪律**：写作阶段专注逻辑，**不检索文献、不编造引用**。每个引用位置写成结构化占位符：`[REF: 主题｜经典奠基/最新进展/竞争工作]`（例：`[REF: 水电解制氢的意义｜经典奠基]`）。一般规律：第一层楼梯的背景用"经典奠基"，中间层的进展用"最新进展"，最后一层的直接竞争用"竞争工作"。全文完稿后统一走 `25-references-citations.md` 检索、核证并插入。成稿写入 `manuscript/14-introduction.md`。
