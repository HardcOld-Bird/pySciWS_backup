# 模块：全文一致性终检（编辑的 3 分钟测试）

> 编辑用 3 分钟看题目→摘要→图→结论就决定送不送审。最致命的破绽不是写得不好，而是**前后不一致**：题目说的核心创新和摘要不是同一个表述、摘要里的 128% 到结论变成 130%、图注和正文对不上。本模块在投稿链条的最后做机械化交叉核对。
>
> 与 sci-peer-review 技能的分工：那边是三人评委会的**深度学术评审**（立意、叙事、严谨性），这边是**轻量机械核对**（表述与数字对齐）。先跑本模块清掉低级伤，再去做深度自审，评委的火力才能集中在真问题上。

## 执行时机

- **主检**：全文中文定稿后、翻译（23 模块）之前。
- **复检**：英文润色（24 模块）之后，快速重跑第 2、3 项（数字与图表引用）——翻译过程可能引入数字或图号错漏。

## 所需输入

全文各部分文本（优先从 `manuscript/` 目录读取；散落的部分让用户粘贴或给路径）+ 论文档案（作为三要素与关键数据的"基准真值"）。

## 七项交叉核对

### 1. 三要素表述一致（最重要）

以论文档案为基准，核对**核心创新 B** 在以下位置是否是同一表述、同一高度、同一类型：
题目前置定语 / 摘要第③句 / 引言最后一段 / 结论第①句 / Highlights 第 1 条 / Cover Letter 卖点段 / 关键词。

典型病症：摘要说"机理创新（揭示了 XX 机制）"，结论却变成"性能创新（性能提升 XX%）"——编辑会认为作者自己都不知道文章的灵魂是什么。分创新点同理核对。

### 2. 数字一致

提取全文所有关键数据（性能数值、提升幅度、测试条件、样品数），逐一核对其在摘要 / 正文 / 图 / 图注 / 结论 / Highlights / Cover Letter 中的**数值、单位、有效位数、测试条件**是否完全一致。输出数字对照表：`数据项 | 档案基准值 | 出现位置1..n | 是否一致`。

### 3. 图表引用完整有序

- 正文按 Figure 1 → N 的顺序**首次**引用，无跳引（先引 Fig. 3 后引 Fig. 2）、无漏引（有图但正文从未引用）、无悬空引用（引用了不存在的图号）。
- SI 引用同理（Fig. S1 → Sn 顺序）。
- 图注内容与正文对该图的描述一致。

### 4. 缩写与术语规范

- 每个缩写在正文**首次出现时定义**（摘要与正文分别独立定义），之后全篇统一使用，不再全称缩写混用。
- 同一概念全文用同一术语（不要一会儿 electrocatalyst 一会儿 catalyst 指同一物）。
- 化学式与单位的上下标规范（H₂O₂ 不写 H2O2、cm⁻² 不写 cm-2）。

### 5. 闭环检查

- 引言提出的科学问题 ↔ 结论是否明确回应？
- 题目给出的预测 ↔ 摘要是否兑现展开？
- 摘要承诺的每个分创新 ↔ 正文是否都有对应图和论证？
- 引言末段预告的关键成果 ↔ 结果部分数据是否吻合？

### 6. 全局红线复查

全稿扫描：novel / new / excellent / best / only 等禁词（可用 ultra-/super-）、's、口语化与缩写（don't 等）、残留的 `[REF: ...]` 或其他占位符、残留的中文（若已是英文稿）。

**动词强度快扫**：全稿搜索 prove / confirm / cause / lead to / demonstrate / establish 等强动词，逐处核对其证据等级（对照 `18-results-discussion.md` 的阶梯表）——计算写了 prove、相关性写了 cause 的，标 🔴。

### 7. 纯翻图测试

只看全部图 + 图注（`manuscript/figure-captions.md`），一个字正文不读，尝试复原"问题→方案→证据→机理"的完整故事线。讲不通的断点（比如从性能图直接跳到结论、机理环节缺图）就是编辑翻图时会卡住的地方，标 🟡 并给补救建议（调图序/改图注/补示意）。

## 输出格式

**问题清单**，按严重度排序：

| 级别 | 定义 |
|---|---|
| 🔴 必须修复 | 三要素表述冲突、数字不一致、悬空/漏引图表、残留占位符 |
| 🟡 建议修复 | 缩写不规范、术语不统一、闭环偏弱 |
| 🟢 提示 | 风格建议 |

每条问题给出：位置（部分+段落）、问题描述、**具体修改建议（直接给改后的句子）**。全部 🔴 清零后，输出一句放行结论："一致性终检通过，可进入翻译/投稿前自审。"

## 自检清单

- [ ] 七项全部执行且以论文档案为基准？
- [ ] 数字对照表完整覆盖所有关键数据？
- [ ] 每条问题都有可直接执行的修改建议？
- [ ] 🔴 清零才放行？
