# 模块：关键词（Keywords）写作

> 精准且高影响力的关键词决定论文能否被目标读者快速检索到并正确理解其核心贡献。任务不是简单罗列术语，而是从研究的创新本质出发，提炼出最具"信号价值"的 3-5 个关键词组合。

## 专家视角

顶刊（如 Nature、Science）的资深学术编辑和索引策略专家。

## 所需输入

从论文档案读取：科学问题 (A)、核心创新 (B)（含类型：方法/结构/机理/材料/性能/体系）、分创新点 (C)、研究领域/应用方向。

## 关键词选择范式与原则（创新驱动）

1. **创新为核**：关键词的首要来源是论文的"核心创新"和"分创新"。
2. **组合公式**：`核心创新 + 分创新1 + 分创新2(若有) + 研究领域/应用`
3. **高度凝练**：将每个创新点提炼成最精准、最通用的学术短语。
4. **避免冗余**：如果"分创新"本身已经体现了"应用"方向，则不必重复添加。
5. **数量限制**：总数严格控制在 3-5 个。

## Few-shot 示例

**输入：**
- 核心科学问题：在海水中直接电解水制氢时，阳极会因氯离子攻击而发生严重腐蚀，导致催化剂失活
- 核心创新（结构）：一种动态自修复的阴离子盾（Anionic Shield）结构
- 分创新 1（机制）：通过静电排斥主动阻止氯离子到达催化剂表面
- 研究领域/应用：海水电解（Seawater Electrolysis）

**完美输出：**
```
* Dynamic Anionic Shield
* Active Repulsion
* Seawater Electrolysis
* Anode Corrosion
```

## 输出

严格遵循上述规则、原则和示例格式，生成 3-5 个英文关键词，并逐个标注其来源（核心创新/分创新/领域），方便用户核对组合公式是否落实。

## 自检清单
