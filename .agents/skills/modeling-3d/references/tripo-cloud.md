# Tripo 云生成口径（⑥域，原型/示意/参考）

**口径一句话**：Tripo（及一切 AI 3D 生成）产物是**任意尺度三角网格（GLB）**，
无参数、无约束、无精确尺寸——只做**原型 / 示意 / 参考**；**精密件一律 bpy 参数化脚本**。
该口径是裁决的一部分，不是建议。

## 通道与版本（2026-11-17 现状）

- **官方 SDK `tripo3d`**（PyPI，MIT，v3 API）——唯一接入通道（豁免 pin：差① star=61，
  厂商唯一官方 v3 SDK，替代=自写 REST 反增自研面；ADR 见选型调研）。
- **Tripo v2 API 已于 2026-10-31 关停**——旧 v2 客户端作废，不迁移不兼容；
  任何 v2 文档/示例勿抄。
- 国内账号走 **tripo3d.com** 域名（blender-mcp 里 .ai/.com 可选）。
- blender-mcp 内置 Tripo 入口（同 key）：**探索用**，产物仍须冻结回脚本（bpy 重建）
  或明确按"参考件"口径使用。

## 科研用法三类（都归"参考"档）

1. **实验装置/复杂实物照片→示意模型**：进③域概念图当背景/示意件；
2. **复杂曲面参考体**：GLB 当视觉参照，在 bpy 里按尺寸重新建模（打印/仿真走这条）；
3. **演示/教学素材**：任意尺度直接用。

能力面（v3）：text/image/multiview→3D（H3.1 高保真+PBR ~40s、P2 原生四边面 ≤5 万面）、
HD/8K 贴图、quad/低模/分件、格式转换（GLTF/FBX/USDZ/OBJ/STL/3MF 互转）、重拓扑、
分割、骨骼动画。计价量级：文生 $0.10–0.20、图生 $0.20–0.30/次，加项 $0.05–0.20。

## 硬红线

- **云网格不直接打印**（print-vs-render 红线之一）：非流形、任意缩放、无壁厚语义。
  要打印 → GLB 只当参照，回 bpy 精确重建 → 过 `judge_print`。
- **任意尺度**：GLB 导入后先核尺度（归一化/按已知参照物定标），别把"导入即 1:1"当真。
- **产物口径标注**：云生成件入渲染/文档时按"示意/参考"标注，不冒充精确模型。
- 本地替代（TripoSR、Hunyuan3D 本地模式）吃 GPU——CPU 机型不可行，云端是本机唯一
  "AI 3D"路线；不引入本地推理。

## 冒烟现状（挂起）

真实出图冒烟**挂起**：`TRIPO_API_KEY` 现状待核（旧项目 .env 待迁），与⑦域真实 API
冒烟同批处理。冒烟脚本就绪后验证链：SDK 调用→任务轮询→GLB 下载→`judge_render`
面数判定→目检。挂起期间接口按官方文档实现、口径按本文执行，不阻塞⑥域交付链
（bpy 全链不依赖 Tripo）。
