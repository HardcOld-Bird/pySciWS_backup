# 非学术网页取证规范

> 适用对象：支撑背景/事实主张的**非学术**网页证据。学术主张一律优先论文引用，
> 网页证据不得替代论文引用。

## 双标签

- **[直取]**：官方/一手页面直接取证（官方文档、发布公告、标准原文、项目仓库）。
  引用时标注页面标题、URL、访问日期。
- **[二手互证]**：仅二手来源可用时，须**两个相互独立**的二手源交叉一致才可采信；
  一致后引用主源并注明"[二手互证]"。单个二手源只能作为线索，不能入正文。

## 来源分级（高→低）

学术论文 > 预印本 > 官方文档/标准 > 权威机构/媒体 > 一般网页/博客 > 聚合站/转载。
低分级来源不得推翻高分级来源；聚合站（内容农场、SEO 汇编）**禁止**当 [直取] 用。

## 403 / 地域封锁决策树

1. 403/429 → 换 UA/退避重试一次（`HTTP_USER_AGENT`、`HTTP_MAX_RETRIES` 见 `.env`）。
2. 仍失败 → 找官方镜像/等价页面（如 arXiv 版、机构库版）→ [直取] 新地址。
3. 无镜像 → 降级 agent web 工具（浏览器渲染）按需抓取；付费墙**不**绕过，改走 OA 回退链或放弃。
4. 全部失败 → 正文标注"[取证失败，仅二手转述]"并降级该主张的置信度，不伪造直取。

## 记录

取证快照（关键引文原文 + URL + 日期）随产物落盘；改版/失效风险高的页面存快照而非只存 URL。
