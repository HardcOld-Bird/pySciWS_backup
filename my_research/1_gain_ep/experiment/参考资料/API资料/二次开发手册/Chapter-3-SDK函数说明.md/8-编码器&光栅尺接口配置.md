3.8.1 MT_Set_Encoder_Z_Polarity
功能描述：设置编码器/光栅尺接口Z信号的电平定义,一般情况下无需设置

public static extern int
MT_Set_Encoder_Z_Polarity
(UInt16 AObj,Int32 Value);
输入参数
AObj
编码器/光栅尺接口序号
输出参数
Value
0:正常电平
1：反向电平
函数返回
0
函数执行成功
非0
函数执行失败
备注
编码器/光栅尺接口的序号从0开始，N轴的卡，序号为0,1,2,3…N-1
编码器/光栅尺接口序号的函数需要注意不要越界
