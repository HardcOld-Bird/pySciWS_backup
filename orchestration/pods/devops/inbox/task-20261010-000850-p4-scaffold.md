`drawing`、`model3d`。参照既有模板：目录结构与 settings/mcp/gitignore 抄

## 各域 charter 领域要点（自检清单素材，写成该域「出具 <result> 前逐项过」清单）

- **sim**（comsol-simulation，CLI `pysci-simulation`）：COMSOL **单许可证纪律**
  （社区 comsol MCP 经 `mcp ensure` 监督、闲时释放；license 被占 → 等待或 blocked，
  绝不并行开两个 COMSOL 实例）；交付前自查收敛性/网格质量指标；.mph 与导出数据
  落 `data/research/<线>/simulation/`（gitignore 区，路径纪律照旧）；渲染自查
  （pyvista/PNG export Read 判读）。
- **writing**（document-writing，CLI `pysci-compose`）：LaTeX 编译链自检
  （latexmk 零 error、chktex 警告已处置或说明）；refs.bib 与 Zotero 同步一致性；
  PDF 渲染页面 Read 视觉校对（至少首页+含图表页）。
- **theory**（theoretical-computation，CLI `pysci-theory`）：符号推导须数值化对拍
  （随机参数代入符号式 vs 数值解，误差阈值写进交付说明）；Unicode 变量纪律
  （与文献一致）；脚本 `# %%` 单元格分块。
- **lit**（literature-research，CLI `pysci-research`）：**代理纪律**（期刊数据库/
  正版全文绝对直连，basic.md §4 已注入你上下文，charter 再强调一次）；检索结果
  按技能模板入库（笔记/INDEX 纪律）；paywall 文献经 unpaywall email 配置合规获取；
  评估类交付给出证据链（期刊分区/引用数据出处）。
- **drawing**（ai-drawing，CLI `pysci-imagine`）：生成图**必须入库 LEDGER**（技能
  自带的生成台账/PNG 内嵌溯源）；交付前 Read 生成图做审美与完整性自检；
  **数据准确性边界**：涉及真实数据可 accuracy 的图（场图/数据图）不由你产出——
  建议组长改派 figure 组员，你只做美学参考/封面/示意图。
- **model3d**（modeling3d，CLI `pysci-model3d`）：打印几何 **trimesh watertight
  验收门**（技能自带）必过；打印管线与渲染管线严格分离（技能红线）；渲染出
  versioned 脚本（不接受纯交互会话产物）；STL 尺寸毫米级核对。
