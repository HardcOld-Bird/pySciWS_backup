### G2 意图对齐核对（generic G2 细化）

逐要素核对**产物元素 ↔ 参考语义 ↔ 物理意图**三方一致；**「数字对但语义错」必须抓出**。
**关系级四项**（见 H4⑤）：**包含拓扑**、**相对大小**、**标注归属**、**近而不交**。
**参考图逐要素对照表**：无「元素→含义→产物→关系→照搬/适配/偏离+理由」表 =
**缺理解痕迹**，按本项 FAIL；sim 另核设置依据表+理论预期预登记。

## 硬项（任一不过 → FAIL）

| # | 硬项 | 检查方法 |
|---|---|---|
| H1 | 科学特征在位 | 主特征（峰/瓣/极值/简并/发散）在**理论预期**位置，对称性/守恒自洽。**任务书可随附最小物理预期陈述**（如「主瓣指向 135°」）——有则据之判定；无依据才记 n/a，**不得据此判 FAIL** |
| H2 | 标注量 = 绘制量 | 标题/轴标签/色标声明的物理量（实部/模/相位/单位）与实际绘制一致。三方对照：数据源列头 ↔ **生成脚本的绘图表达式** ↔ 图面标注；**硬判定优先直接证据**（图面/列头），脚本仅作佐证 |
| H3 | 无渲染伪影 | 无插值/包络/非物理区域着色/杂色；非目标结构按需求隐去；**外部渲染器品牌/UI 元素是否已清除**。视觉判读 + 对照原始渲染（`pysci-figures inspect`） |
| H4 | 排版无破损（**零遮挡铁律**，硬伤级） | 五条**逐项**过：①**文字/刻度值不压主图图线、彩色数据区**（实案 `Sim.` 压色块 **18px**）②**图体与标题留间距**③**colorbar 标题↔色标、色标↔子图留边距**④**任何元素重叠（含标题压 colorbar）=FAIL 无例外**⑤**近而不交**：不该相交的线/框须保持距离，**贴边/临界间距＝缺陷（与重叠同级）**。判法：**像素级为真源**——差分白字渲染 + 蒙版求交（**墨迹蒙版** ∩ 图线/彩色数据区蒙版，**交叠即遮挡**，报像素数与最短距）；**bbox 相交仅粗筛**（**实测 8 报 8 假阳**），须像素级复核；整图+放大；scaffold `audit`；文字块间距用 `ink-gap`（禁自写测距） |
| H5 | 数据可追溯 | 每个数值/色块可追到数据文件与生成脚本，中间产物集中。核实路径与脚本并抽查复算；**粘贴型栅格子图**（外部渲染直贴、无数值件）记「**图像级可追溯（不可数值复算）**」并如实标注 |
| H6 | 处置分支与用户指令对齐 | 任务书有「处置分支声明」时产物须走**指定分支**；偏离、或回退**用户显式指令**且无 `<blocked>`/疑问清单上报留痕 → FAIL。核对声明↔实现↔上报记录 |
| H7 | 仿真域声明 / 标度与量程 | sim 图须附「域几何声明」四问（兼容性/覆盖率/边界适配/激励口径）且每问带数值；缺项/敷衍＝FAIL；激励口径须含工作点 (cr,ci)↔最近 EP 偏移与寻点出处（`domain-check` 机械核）。多组对照独立 colorbar/量程（禁统一，除非明示可比）；标度匹配数据性质（线性默认，禁对数除非明示）；**vmax 自适应**：vmax÷显示区（严格 y>0 气域、r≤ROI）实测 max\|Re p_t\|∈[1.0,1.1]，读实测非声明值（`pysci-figures vmax-check`） |

## 评分维度（0–5，**记录用，不阻断 PASS**）

| 维度 | 检查要点（通用） | 判定方法 / 命令 |
|---|---|---|
| D1 科学正确性与物理自洽 | 主特征位置正确；对称性/守恒自洽；采样充分无欠采样伪影 | 物理判据 + 数据抽查；对称轴两侧幅值/形态对照（**任务书随附最小物理预期陈述时以之为判据**，否则记 n/a） |
| D2 量与标度 | 标注量=绘制量；标度适配数据范围；色标刻度 3~5 条、单位量级清晰 | 标题/色标/数据源三方对照；刻度计数；色标上限与数据 max 比对 |
| D3 标注与几何保真 | 几何标注按物理尺寸换算绘制（非目测）；标签语义正确；引线连接对应；标注不遮挡数据 | 换算复核，或由图面**自标定**反算：轴范围/刻度 → **像素→物理尺寸**，**不依赖生产者 notes**；标签逐个读；结构化标注跑 `pysci-figures audit`（ANNOTATIONS.yaml 四判据） |
| D4 洁净度 | 无插值/渲染伪影；非目标结构按需求隐去；**外部渲染器品牌/UI 元素已清除**；边框干净 | 视觉判读 + `pysci-figures inspect <png>` 边缘标记扫描 |
| D5 排版与可读性 | 分组/同轴可比/共享色标等高；**零遮挡铁律词表**：文字压图线、刻度压图线、彩色数据区、标题贴身、colorbar 标题压色标、色标压子图、任何元素重叠；**设计用色 1~2 个色系**。**布局节奏/编号锚定四条**：①标题与上方外缘间距 > 与下方子图间距；②图例置于数据图下方、不压主体；③子图组与脚注段留清晰间距；④子图编号按**整体 bbox（含图例/colorbar/标注）左上角**锚定 | 视觉判读 + `pysci-figures audit`；**色觉安全**：`audit.simulate_cvd(rgb,"deutan")` 模拟后两两色距 < **0.12** 即告警；**色系计数口径**：数设计用色、不数数据 colormap；Rainbow 类不计入，**豁免计数但不免协调义务**（取同族/中性色，**勿另起色系**，至多 1 个协调点缀色系） |
| D6 全图一致性 | 标题↔色标↔数据量一致；风格统一；与约定样式一致 | 逐元素对照 |

## 工具与命令

- **视觉判读**：`Read` 整图 → 逐子图（`panels/`、`raw/`）；精确坐标用 `pysci-figures raster-panel`。
- **图像体检（不依赖管线）**：`pysci-figures inspect <png>`——尺寸/色域/饱和像素/**边缘水印·logo 检测**。
- **规范自检**：`pysci-figures audit <figdir> [--panels]`（scaffold）；`doctor` 查工具链。
- **遮挡判法（H4）**：差分白字渲染 → 墨迹蒙版 `ink = |A − A_text→white| > 30` → 与图线/彩色数据区**求交**；**阈值：重叠 > 0 px＝FAIL，最小间距 < 10 px @600 dpi＝缺陷**。
- **标注几何（H6/D3 指定工具）**：图目录 `ANNOTATIONS.yaml` 声明语义模型 + 图中 `gid="annot:<id>"`；`pysci-figures audit` 核验计数/包含+边距/相对大小/连接线（schema 见 scientific-plotting 分册 4）。

## 审查流程

1. **视觉判读**：整图 → 逐子图，先记可疑处。
2. **工具核验**：`audit`（scaffold）/ **`inspect <png>`（任意产物）** + 数据源追溯 + 几何复核。
3. **物理判据核对**（D1）：任务书/文献给足依据才判，否则记 n/a。
4. **维度评分 + 硬项判定**：H1–H7 逐条过；任一不过 → FAIL，VERDICT 附**可执行**返工指引。

## 非 scaffold 图目录的边界

`pysci-figures audit` 依赖图目录内管线 `.py`；散落脚本的图目录返回 `N/A (非 scaffold 产物)`
——**不是 FAIL**：核验改由 **`pysci-figures inspect <png>`** 承接，evidence 注明「audit 不适用本产物」。

## VERDICT 规则

- generic 硬项 + 本表 H1–H7 全过 → PASS（D1–D6 评分如实记录，低分不阻断）；
- 任一硬项不过 → FAIL，evidence 给硬项编号、复现命令与可执行返工指引；**量值须注明量的是什么**（如「间距 18px」＝文字墨迹↔图线/色块的像素最短距）；
- 工具链不可用/依据不足 → 记 n/a 并说明，**不得据此判 FAIL**。
