### G2 意图对齐核对（generic G2 的判定细化；引用参考材料时必做）

逐要素核对**产物元素 ↔ 参考语义 ↔ 物理意图**三方一致：按任务书「参考材料语义对齐」段
（全集/用途边界/解构表/疑问清单）建映射，再逐元素回验语义与物理意图相符。**「数字对但语义错」
必须抓出**（参数对 ≠ 语义对，如尺寸全对却把「位置标记框」画成独立「扫描范围框」）；存疑即记疑问或 FAIL。

## 硬项（任一不过 → FAIL）

| # | 硬项 | 检查方法 |
|---|---|---|
| H1 | 科学特征在位 | 主特征（峰/瓣/极值/简并/发散）出现在**理论预期**位置，对称性/守恒自洽。**任务书可随附最小物理预期陈述**（如「L 入射主瓣指向 135° 输出通道」）——有则以之为判据（H1/D1）；无依据才记 n/a，**不得据此判 FAIL** |
| H2 | 标注量 = 绘制量 | 标题/轴标签/色标声明的物理量（实部/模/相位/单位）与实际绘制的数据一致。三方对照：数据源列头 ↔ **生成脚本的绘图表达式** ↔ 图面标注；**硬判定优先直接证据**（图面/数据列头），脚本仅作佐证 |
| H3 | 无渲染伪影 | 无插值/包络/非物理区域着色/杂色；非目标结构按需求隐去；**外部渲染器品牌/UI 元素是否已清除**。视觉判读 + 与原始数据渲染对照（`pysci-figures inspect`） |
| H4 | 排版无破损（**零遮挡铁律**，硬伤级） | 四条**逐项**过：①**文字/刻度值不压主图图线、彩色数据区**（处理=移位且保语义，如雷达幅值刻度移至直径边；实案 `Sim.` 标签压场图色块 **18px**）②**图体与标题留间距**③**colorbar 标题↔色标、色标↔子图留边距**④**任何元素重叠（含标题压 colorbar）=FAIL 无例外**。判法：**像素级为真源**——差分白字渲染（把标注/刻度文字改白重渲染）+ 蒙版求交（文字墨迹蒙版 ∩ 真实图线/彩色数据区蒙版，交叠即遮挡，报像素数与最短距）；**bbox 相交仅粗筛**（多行 `fig.text` 行距与数学标签 bbox 偏大，实测 8 报 8 假阳），须像素级复核；整图+放大裁剪逐项判读；scaffold 加 `pysci-figures audit` |
| H5 | 数据可追溯 | 每个数值/色块可追到数据文件与生成脚本，中间产物集中。核实数据源路径与脚本，抽查复算；**粘贴型栅格子图**（外部渲染直贴、无数值件）记「**图像级可追溯（不可数值复算）**」并如实标注，或要求保留导出数值 |

## 评分维度（0–5，**记录用，不阻断 PASS**）

| 维度 | 检查要点（通用） | 判定方法 / 命令 |
|---|---|---|
| D1 科学正确性与物理自洽 | 主特征位置正确；对称性/守恒自洽；采样充分无欠采样伪影 | 物理判据 + 数据抽查；对称轴两侧幅值/形态对照（**任务书随附最小物理预期陈述时以之为判据**，否则记 n/a） |
| D2 量与标度 | 标注量=绘制量；标度适配数据范围（弱组不被强组淹没）；色标刻度 3~5 条、单位与量级清晰、不越界 | 标题/色标/数据源三方对照；刻度计数；色标上限与数据 max 比对 |
| D3 标注与几何保真 | 几何标注按物理尺寸换算绘制（非目测）；标签语义正确（组别/方向/坐标）；引线连接对应；标注不遮挡数据 | 换算复核（物理尺寸→图上坐标手算）；标签逐个读 |
| D4 洁净度 | 无插值/渲染伪影；非目标结构按需求隐去；**外部渲染器品牌/UI 元素已清除**；边框干净 | 视觉判读 + 对照原始数据渲染 + `pysci-figures inspect <png>` 边缘标记扫描 |
| D5 排版与可读性 | 布局服务比较逻辑（子图分组/排列与比较维度一致）；同轴可比内容合并减重复；共享色标对齐等高；**无遮挡/重叠（零遮挡铁律词表：文字压图线、刻度压图线、彩色数据区、标题贴身、colorbar 标题压色标、色标压子图、任何元素重叠）**；线色区分度（色觉安全）；**设计用色色系克制**（整图设计用色——曲线/标注/边框/背景/装饰——一般 **1~2 个色系**，同图红黄蓝绿并用即杂乱） | 视觉判读 + `pysci-figures audit`；**色觉安全有可执行判定**：`audit.simulate_cvd(rgb,"deutan")` 模拟后两两色距 < **0.12** 即告警；**色系计数口径：数「设计用色」的色系归属，不数数据 colormap**——Rainbow 类为必选项时不计入色系计数，即豁免计数但不免协调义务（设计用色取该 colormap 同族或协调中性色/灰阶，勿另起色系；「1~2 色系」= 同族 + 至多 1 个协调点缀色系） |
| D6 全图一致性 | 标题↔色标↔数据量一致；风格统一；与约定样式（期刊/参考图）一致 | 逐元素对照 |

## 工具与命令

- **视觉判读**：`Read` 整图 PNG → 再逐子图 `Read`（`panels/`、`raw/`）；需要精确坐标时
  `pysci-figures raster-panel` 叠加数据坐标核验位置。
- **图像体检（不依赖管线）**：`pysci-figures inspect <png>`——尺寸/色域占用/饱和像素占比/
  **边缘水印·logo 检测**（非 scaffold 产物核验由它承接，见下）。
- **规范自检**：`pysci-figures audit <figdir> [--panels]`（**仅 scaffold 产物**，见下）；
  `pysci-figures doctor` 查工具链健康。
- **数据可追溯**：读 `raw/*.csv` 列头核量纲；数值源可用 `pysci-simulation export ...` 复核；
  按声明模型手算抽查。
- **样式基准**：`pysci-figures styles`；图目录 `STYLE.yaml` 声明 width/style。

## 审查流程（通用四步）

1. **视觉判读**：整图 → 逐子图，先只记可疑处，不急着下判。
2. **工具核验**：`pysci-figures audit`（scaffold）/ **`pysci-figures inspect <png>`（任意产物）**
   + 数据源追溯 + 几何换算复核。
3. **物理判据核对**（D1）：任务书/文献给足依据才判，否则记 n/a。
4. **维度评分 + 硬项判定**：H1–H5 逐条过；任一不过 → FAIL。VERDICT 附**可执行**返工指引
   （哪张子图、改哪个量、目标值）。

## 非 scaffold 图目录的边界

`pysci-figures audit` 依赖图目录内的管线 `.py`；散落脚本产出的图目录返回
`N/A (非 scaffold 产物)`——**这不是 FAIL**：核验改由 **`pysci-figures inspect <png>`**
（尺寸/色域/饱和像素/边缘水印·logo，不依赖管线）承接，evidence 注明「audit 不适用于本产物」。

## VERDICT 规则

- generic 硬项 + 本表 H1–H5 全过 → PASS（D1–D6 评分如实记录，低分不阻断）；
- 任一硬项不过 → FAIL，evidence 给出硬项编号、复现命令与可执行返工指引；**量值须注明量的是什么**
  （如「间距 18px」= 文字墨迹↔图线/色块的像素最短距）；
- 工具链不可用或依据不足 → 记 n/a 并在 evidence 说明，**不得据此判 FAIL**。
