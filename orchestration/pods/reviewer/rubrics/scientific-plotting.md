# 科研绘图通用审查量表（scientific-plotting）v0.3

> **状态：已生效**，适用于任何**数据驱动的科研图件**（散点/色图/极坐标/多子图排版/示意图），
> 不限本课题。与 `generic.md` 的关系：generic 是任意产物的最低限度审查，本表是**视觉图件**
> 的专用量表——两者**叠加**：先过 generic 硬项（存在/可读/目标一致/自检/无破碎），再按下表
> 逐维度审。高利害纪律沿用 generic：**依据不足的维度记 n/a，不臆断、不发明标准**。
>
> **v0.3（2026-10-15）**：首次实审校准（I.i3 报告 §4）后的修订，六处——H1/D1 物理预期输入、
> H2 第三方证据、H3/D4 外部渲染器元素、H5 粘贴型栅格口径、D5 色觉安全可执行判定、
> 新工具 `figures inspect`（见各条与「工具与命令」）。
>
> **适用边界**：不覆盖纯艺术插画或无数据语义的装饰图；论文整篇审查用文档量表。
> 任务书若给出更具体的 rubric，以任务书为准（本表退为兜底）。

## 硬项（任一不过 → FAIL）

| # | 硬项 | 检查方法 |
|---|---|---|
| H1 | 科学特征在位 | 主特征（峰/瓣/极值/简并/发散）出现在**理论预期**位置，对称性/守恒自洽。**任务书可随附最小物理预期陈述**（如「L 入射主瓣指向 135° 输出通道」）——有则以之为判据（H1/D1）；无依据才记 n/a，**不得据此判 FAIL** |
| H2 | 标注量 = 绘制量 | 标题/轴标签/色标声明的物理量（实部/模/相位/单位）与实际绘制的数据一致。三方对照：数据源列头 ↔ **生成脚本的绘图表达式** ↔ 图面标注；**硬判定优先直接证据**（图面/数据列头），脚本仅作佐证（脚本 mtime 未必同版本） |
| H3 | 无渲染伪影 | 无插值/包络/非物理区域着色/杂色；非目标结构按需求隐去；**外部渲染器品牌/UI 元素（logo、水印、坐标网格 UI）是否已清除**。视觉判读 + 与原始数据渲染对照（`pysci-figures inspect`） |
| H4 | 排版无破损 | 无文字溢出/遮挡/裁切，子图互不覆盖，线色区分度足够（色觉安全）。视觉判读；scaffold 产物加 `pysci-figures audit` |
| H5 | 数据可追溯 | 每个数值/色块可追到数据文件与生成脚本，中间产物集中。核实数据源路径与脚本，抽查复算；**粘贴型栅格子图**（外部渲染直贴、无数值件）记「**图像级可追溯（不可数值复算）**」并如实标注，或要求保留导出数值 |

## 评分维度（0–5，**记录用，不阻断 PASS**）

| 维度 | 检查要点（通用） | 判定方法 / 命令 |
|---|---|---|
| D1 科学正确性与物理自洽 | 主特征位置正确；对称性/守恒自洽；采样充分无欠采样伪影 | 物理判据 + 数据抽查；对称轴两侧幅值/形态对照（**任务书随附最小物理预期陈述时以之为判据**，否则记 n/a） |
| D2 量与标度 | 标注量=绘制量；标度适配数据范围（弱组不被强组淹没）；色标刻度 3~5 条、单位与量级清晰、不越界 | 标题/色标/数据源三方对照；刻度计数；色标上限与数据 max 比对 |
| D3 标注与几何保真 | 几何标注按物理尺寸换算绘制（非目测）；标签语义正确（组别/方向/坐标）；引线连接对应；标注不遮挡数据 | 换算复核（物理尺寸→图上坐标手算）；标签逐个读 |
| D4 洁净度 | 无插值/渲染伪影；非目标结构按需求隐去；**外部渲染器品牌/UI 元素已清除**；边框干净 | 视觉判读 + 对照原始数据渲染 + `pysci-figures inspect <png>` 边缘标记扫描 |
| D5 排版与可读性 | 布局服务比较逻辑（子图分组/排列与比较维度一致）；同轴可比内容合并减重复；共享色标对齐等高；无溢出/重叠；线色区分度（色觉安全） | 视觉判读 + `pysci-figures audit`；**色觉安全有可执行判定**：`audit.simulate_cvd(rgb,"deutan")` 模拟后两两色距 < **0.12** 即告警（阈值即 audit 的 `colorblind` 判据） |
| D6 全图一致性 | 标题↔色标↔数据量一致；风格统一；与约定样式（期刊/参考图）一致 | 逐元素对照 |

## 工具与命令

- **视觉判读**：`Read` 整图 PNG → 再逐子图 `Read`（`panels/`、`raw/`）；需要精确坐标时
  `pysci-figures raster-panel` 叠加数据坐标核验位置。
- **图像体检（不依赖管线）**：`pysci-figures inspect <png>`——尺寸 / 色域占用 / 饱和像素占比 /
  **边缘水印·logo 检测**；**非 scaffold 产物**的工具核验由它承接（audit 在那类目录恒 N/A）。
- **规范自检**：`pysci-figures audit <figdir> [--panels]`（**仅 scaffold 产物**，见下）；
  `pysci-figures doctor` 查工具链健康。
- **数据可追溯**：读 `raw/*.csv` 列头核量纲；数值源可用 `pysci-simulation export ...` 复核；
  按声明的模型手算抽查（如 ω± = ω̄ ± √(δ²+κ²) 一类）。
- **样式基准**：`pysci-figures styles`；图目录 `STYLE.yaml` 声明 width/style。

## 审查流程（通用四步）

1. **视觉判读**：整图 → 逐子图，先只记可疑处，不急着下判。
2. **工具核验**：`pysci-figures audit`（scaffold 产物）/ **`pysci-figures inspect <png>`
   （任意产物）** + 数据源追溯 + 几何换算复核。
3. **物理判据核对**（D1）：任务书/文献给足依据才判，否则记 n/a。
4. **维度评分 + 硬项判定**：H1–H5 逐条过；任一不过 → FAIL。VERDICT 附**可执行**返工指引
   （哪张子图、改哪个量、目标值），而非泛泛描述。

## 非 scaffold 图目录的边界

`pysci-figures audit` 依赖图目录内的管线 `.py`（或 src 侧同名脚本）。散落脚本产出的图目录
（无 scaffold 管线）返回 `N/A (非 scaffold 产物)` 副值——**这不是 FAIL**。此类产物的工具核验
改由 **`pysci-figures inspect <png>`** 承接（尺寸/色域占用/饱和像素占比/边缘水印·logo 检测，
不依赖管线）；再加上「视觉判读 + 数据追溯」，并在 evidence 中注明「audit 不适用于本产物」。

## VERDICT 规则

- generic 硬项 + 本表 H1–H5 全过 → PASS（D1–D6 评分如实记录，低分不阻断）；
- 任一硬项不过 → FAIL，evidence 给出硬项编号、复现命令与可执行返工指引；
- 工具链不可用或依据不足 → 记 n/a 并在 evidence 说明，**不得据此判 FAIL**。
