# 演示文稿通用审查量表（presentation）v0.2

> **状态：已生效**，适用于任何**幻灯片 / 演示文稿类产物**（.pptx 汇报、答辩稿、方案宣讲），
> 不限课题。与 `generic.md` **叠加**：先过 generic 硬项（存在/可读/目标一致/自检/无破碎），
> 再按下表逐维度审；高利害纪律沿用 generic（**依据不足记 n/a，不臆断、不发明标准**）。
>
> **v0.2（2026-10-16）**：几何体检端点 `compose slides geometry`（H4①/H2 的机械原料）；
> H2 补两条判法前提（字体未落盘 / SHAPE_TO_FIT_TEXT）；受审目录只读时的合规渲染路径。
>
> **适用边界**：不覆盖单页长文档（论文/报告）——整篇文档审查用文档量表；纯模板样式审查、
> 不涉内容语义时 H5 记 n/a。任务书若给出更具体的 rubric，以任务书为准（本表退为兜底）。
>
> **前置：逐页视觉核验不可跳过。** 演示文稿是**视觉产物**——文字在版面上如何排布、图与字
> 如何互证，只有看到渲染图才判得了；**未逐页 Read 渲染图即下 PASS ＝ 未审**。文字提取稿
> （`compose slides extract`）只作对照佐证，不能替代视觉判读。

## 硬项（任一不过 → FAIL）

| # | 硬项 | 检查方法 |
|---|---|---|
| H1 | 逐页视觉核验到位 | **每一页**都 Read 了整页渲染 PNG 并逐页判读；渲染页数 = 幻灯片页数、无空白页（先跑机械闸 `compose slides verify`，非 0 即打回）。跳页 / 只看文字提取稿即判 PASS ＝ 评审失效 |
| H2 | 文字可读性（投影直觉） | 正文/标注字号按**投影距离**核（远端观众可读）：字号过小、对比不足（深底深字 / 浅底浅字）、文字溢出文本框被裁 ＝ 硬伤。判法：渲染图上量字高与边距，或 `compose slides extract` 对照文本框。**两条前提**（防字体/自增长假阳性）：①**字体未落盘**（deck 用了本机没有的字体族、渲染器静默替换）→ 由渲染图推出的**行距 / 折行**判定**降级为提示**、不作硬项；②`autosize=SHAPE_TO_FIT_TEXT` 的文本框会自增长、PowerPoint 与渲染器结果可不同 → **不据渲染图判其溢出** |
| H3 | 图文一致 | 图中/表中的量、量纲、组别与同页文字所述**一致**；无「说的 A 画的是 B」、无错配素材（张冠李戴的图/表）；引用数据可追到素材 / 调研来源 |
| H4 | 版式无遮挡 + 与模板美学一致（**零遮挡铁律**，硬伤级） | ①任何元素重叠（文字压文字 / 压图 / 压边框、图压字、元素出画布被裁）＝ FAIL 无例外；②与模板一致：字体族 / 字号阶梯 / 主题配色 / logo 与页眉页脚位置 / 留白量沿用模板，不自起风格。判法：渲染图整页 + 放大可疑处判读，与母版同页对照 |
| H5 | 面向非专业听众的信息密度 | 单页**勾勒主体 + 少量关键细节**（一个主导论点 + 2–4 条支撑），不塞满、不堆长段落；术语首现给一句白话解释；原始报告的长段落不入页，详略服务叙事而非罗列 |

## 评分维度（0–5，**记录用，不阻断 PASS**）

| 维度 | 检查要点（通用） | 判定方法 / 命令 |
|---|---|---|
| D1 叙事结构 | 全篇有清晰主线（问题→方法→结果→结论），页序推进不自相矛盾；每页服务一个论点 | 逐页读标题与要点，串成一句话主线自检 |
| D2 信息密度与留白 | 单页信息量与留白平衡；无「一页讲三件事」也无一页仅一句空话；关键页有视觉锚点 | 视觉判读 + 要点计数 |
| D3 文字可读性 | 字号阶梯分明（标题 > 正文 > 注释）、行距与对齐一致、无标点 / 断行事故 | 渲染图逐页判读 |
| D4 视觉一致性 | 主题配色 / 字体 / 项目符号 / 图表风格全篇统一；同类页版式一致（如每节首页同构） | 跨页对照 |
| D5 图文互证与素材质量 | 图 / 表清晰（非糊图 / 拉伸变形 / 低分辨率截图）、与文字互证；素材版权 / 来源合规 | 放大判读 + 素材溯源 |
| D6 洁净度 | 无占位符（TODO / 待填 / xxx）、无临时标记（红框 / 编辑批注 / 水印）、无拼写错误、无空文本框骨架 | 渲染图判读 + `compose slides extract` 全文检索占位词 |

## 工具与命令

- **逐页渲染（视觉判读前置）**：`compose slides render '<deck.pptx>'`——固化 pptx→pdf→逐页
  PNG 链，产出 `<deck>_render/page-NNN.png`（供 Read）；页数应与幻灯片数一致。
- **机械视觉闸（先跑）**：`compose slides verify '<deck.pptx>'`——校验渲染存在、页数 = 幻灯片数、
  非空白页；退出码非 0 即打回（缺渲染 / 页数不符 / 空白页）。派发侧已注册为
  `check="pptx-visual"`，交付声明该 check 即由 orch 自动跑。
- **几何体检（版面硬伤，只读、不写盘）**：`compose slides geometry '<deck.pptx>' [--frame NAME] [--json]`——
  纯 bbox + z 序硬判三类数值：**外框边被更高 z 序图片覆盖率** / **图元越界**（画布与外框）/
  **图片互叠面积**；不渲染、不写盘，故**受审目录只读时照跑**。加 `--strict` 有违规即退出码非 0。
  H4① 与 H2 的原料由此而来，**不必自建脚本**；外框默认自动识别（画布面积 10%–95% 的最大矩形），
  识别不准时用 `--frame <形状名>`。
- **只读受审目录的合规渲染路径**：受审目录禁写时用
  `compose slides render '<deck.pptx>' --out <可写目录>`（渲染后**打印可直接粘贴的 verify 命令**，
  不必记 `--render-dir` 旗标名）；或请任务书白名单许可受审目录旁的 `<stem>_render/`。
- **视觉判读**：`Read` 每页 `<deck>_render/page-NNN.png` 整页，再对可疑页放大裁剪判读。
- **文本核对**：`compose slides extract '<deck.pptx>'`——逐页标题 / 要点 / 表格 / 备注 / 图片清单，
  用于图文一致与占位符检索（**注意：文字提取稿不能替代视觉判读**）。
- **模板对照**：与任务书给的模板 `.pptx`（母版文本框 / 配色 / logo）逐项对照。

## 审查流程（通用四步）

1. **视觉判读**：`compose slides render` 后**逐页 Read** 渲染 PNG，整页 → 可疑处放大，先只记
   可疑点，不急着下判。
2. **工具核验**：`compose slides geometry`（遮挡 / 越界 / 互叠 —— H4①/H2 的几何原料）
   \+ `compose slides verify`（渲染存在 / 页数一致 / 非空白）+ `compose slides extract` 对照文本框与占位符。
   **同时核对任务书陈述的产物事实**（页数 / 画布尺寸等）与工具实测——**不符以实测为准**并在
   evidence 记 discrepancy：任务书事实由派发侧手写，实测曾与实况不符（载 3 页实为 5 页），照信即漏审。
3. **内容对照素材 / 调研**：逐页图文与任务书素材、调研报告核对（H3 / D5），素材来源可追。
4. **判定**：H1–H5 逐条过，任一不过 → FAIL；VERDICT 附**可执行**返工指引（哪一页、改什么、
   目标值）。

## VERDICT 规则

- generic 硬项 + 本表 H1–H5 全过 → PASS（D1–D6 评分如实记录，低分不阻断）；
- 任一硬项不过 → FAIL，evidence 给出硬项编号、复现命令（`slides render/verify` + 页码）与
  可执行返工指引；
- 工具链不可用（如 LibreOffice 缺、渲染链跑不通）或依据不足 → 记 n/a 并在 evidence 说明，
  **不得据此判 FAIL**；
- **视觉判读证据**：evidence 须写明「已逐页 Read N 页渲染图」，而非仅引文字提取稿。
