# 通用审查量表（generic）——最小占位版 v0.1

> **状态**：占位符/流程验证用，判定从宽。正式版（科学正确性/成果创新性/绘图美观性
> 等复杂维度，可能配套专属技能与程序基础设施）待项目框架稳定后由用户与组长深度
> 共议修订（用户裁决 2026-10-09）。修订前**不得**据本量表做高利害判定。

## 适用性

任意产物类型的最低限度审查。任务书可指定更具体的 rubric 覆盖本表。

## 检查项（全部为硬项，任一不过 → FAIL）

| # | 检查项 | 判定方法 |
|---|---|---|
| G1 | 产物存在且可读 | 文件/目录可访问；图件能被 Read 打开 |
| G2 | 与任务书目标一致 | 产物内容对应任务书声明的意图（主题/数据/形式） |
| G3 | 生产者自检已完成 | 交付声明了机械验收（check≠none）或给出了豁免理由 |
| G4 | 无明显质量缺陷 | 图件：Read 预览无布局破碎/文字溢出/标注遮挡；文档：结构完整无占位残留；数据：可解析且维度自洽 |

## 评分维度（0–5，记录用，不影响 PASS/FAIL）

- 规范性：格式/命名/元数据符合领域惯例的程度；
- 美观度：仅对视觉产物——布局、配色、可读性；
- 科学正确性：仅在任务书提供足够依据时评估，否则记 n/a；
- 创新性：仅在任务书要求时评估，否则记 n/a。

## VERDICT 规则

- 全部硬项通过 → PASS（评分维度如实记录，低分不阻断）；
- 任一硬项不过 → FAIL，evidence 中给出对应 G 编号与可执行返工指引。
