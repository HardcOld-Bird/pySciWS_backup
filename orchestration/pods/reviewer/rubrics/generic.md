# 通用审查量表（generic）——最小占位版 v0.1

> **状态**：占位符/流程验证用，判定从宽。正式版（科学正确性/成果创新性/绘图美观性
> 等复杂维度，可能配套专属技能与程序基础设施）待项目框架稳定后由用户与组长深度
> 共议修订（用户裁决 2026-10-09）。修订前**不得**据本量表做高利害判定。

## 适用性

任意产物类型的最低限度审查。任务书可指定更具体的 rubric 覆盖本表。

## 检查项（全部为硬项，任一不过 → FAIL）

| # | 检查项 | 判定方法 |
|---|---|---|
| G1 | 产物存在且可读 | 文件/目录可访问；图件能被 Read 打开 |
| G2 | 与任务书目标一致 | 产物内容对应任务书声明的意图（主题/数据/形式） |
| G3 | 生产者自检已完成 | 交付声明了机械验收（check≠none）或给出了豁免理由 |
| G4 | 无明显质量缺陷 | 图件：Read 预览无布局破碎/文字溢出/标注遮挡；文档：结构完整无占位残留；数据：可解析且维度自洽 |
| G5 | 品牌／型号双向判据 | 写型号前先自问静态知识库是否**熟知**该品牌：本领域名牌与「不知所云的型号」（如步进电机 `MT-22E`）应一眼可辨。**熟知（名牌）保留品牌+型号**：白名单 `YAMAHA`、`NI`、`GRAS`（用户点名 2026-10-17；维护规则=用户点名即增补，与 writing charter 判据 1 同一份）；**不熟（冷门）不写**，降为**功能 + 关键规格层级**（如「二维步进电机驱动台」）；判不准按冷门处理并列入疑问清单。名牌核心仪器的品牌+型号与 G7 并行不悖（机箱/瓦数/辐射面积等琐碎规格仍省略） |
| G6 | 学术口吻（默认） | 无任务书特别强调时，文字为学术写作口径：专业、严谨，无口语化表达（如「槽内放一支」） |
| G7 | 琐碎细节已省略 | 未堆砌琐碎工程参数（功放瓦数、机箱型号、辐射面积）与过程性流水叙述；已提取核心概括 |
| G8 | 仿真设置类根因批语附核验 | 「误用 PML / 边界设错」这类**根因断言**产出前，须附一条**对盘核验命令及其输出**（如 `pysci-simulation inspect node --mph M --path …` 的属性 dump、或 `inspect feature-types` 的特征清单），或 sim 侧先出「设置依据表」再定根因——未经核验的根因批语不成立（tb-20261017-090108） |
| G9 | 真源一致／禁回退 | 修订替换类：逐句判定须对照**内容真源文件**逐项核实**全部事实**（含批语未点名处）；批语/参考材料中作**示例**的句式只仿**形式**，数字与术语必须取自真源，**禁照抄示例数字**。任务书「**禁回退事实清单**」逐条保证不回退——**已写对的内容改错＝硬缺陷**。抽查对照任务书事实清单/真源 |
| G10 | 格式标注逐处对照 | 修订类 docx：每处被判不实的内容**留原位**红底 + 删除线，每处替换新文本**黄底 + 加粗**，逐处对照无遗漏；交付文字写「**标删除线留原位**」，**禁以「删除」代替** |

## 抽查项（记录用，**不**单独判 FAIL；命中即写进 evidence 并给返工建议）

- **修订替换类任务**：交付与原稿的 diff 是否**最小**——原内容**逐句**判定属实即保留
  （含位置），仅替换不实部分；出现**整段重写**时按返工建议报出。

## 评分维度（0–5，记录用，不影响 PASS/FAIL）

- 规范性：格式/命名/元数据符合领域惯例的程度；
- 美观度：仅对视觉产物——布局、配色、可读性；
- 科学正确性：仅在任务书提供足够依据时评估，否则记 n/a；
- 创新性：仅在任务书要求时评估，否则记 n/a。

## VERDICT 规则

- 全部硬项通过 → PASS（评分维度如实记录，低分不阻断）；
- 任一硬项不过 → FAIL，evidence 中给出对应 G 编号与可执行返工指引。
