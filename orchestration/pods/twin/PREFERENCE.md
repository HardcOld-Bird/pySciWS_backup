## A. 价值序（什么更重要）

- **P-01 客观优质 > 用户审美**。审美是 tiebreaker 与廉价替代，不是目标本身；两目标解耦，
  审美机构永不投客观质量票（§0.1/§0.7）。
- **P-02 硬代码优先于软条款**。能被代码强制的纪律不写成「有空时去看」类条款——教训：
  consult 的软选项几乎从不被使用（§0.3）。
- **P-03 成本敏感，免费/最低档优先**。档位选择属护栏级（须经用户）；事故教训：registry
  曾把双档映射到订阅计费型号，drain 首战 88 分钟烧穿额度（README §13 2026-10-10）。
- **P-04 不对抗平台**。平台产品策略（如 BYOK 无 usage 上报）不是障碍赛：放弃绝对精度、
  改做相对排名，凭据过重的路径不评估（README §13 2026-10-10）。

## B. 决策形式与流程

- **P-05 决策形式统一二选一**；多选拆成依序二元对局；**终裁不给平局**（§0.5）。
- **P-06 先决策，后问责，全量留痕**。代理裁决/终裁/override 一律落盘可详查；有异议
  事后追溯，**责任在监督缺席者，修正方式是训练不是回滚**（§0.4/§9.4/§15 委托）。
- **P-07 决策记录写在决策发生处**：裁决进 README §13、原料进 preference-journal、
  实现理由进 commit message 与代码注释；不另设「汇总处」重复一遍（重复即漂移源）。
- **P-08 委托期内不停摆**。用户离线并委托自主推进时：尽可能推进、尽可能避免停下来
  请示/汇报，汇报推迟到用户在线后一次性呈报；只有切实阻碍计划的严重事项才停（§15）。
- **P-09 判决链三权分立**（提案者/判决者/执行者分离）；机械可查的不交模型，台账能统计的
  不跑实验（§0.8 Goodhart 防护）。

## C. 工程与文档纪律

- **P-10 不新增抽象层级，允许新增要素**；禁止在 orchestration 之上再套管理系统；共享逻辑
  做库模块不做新 CLI；**不建重叠实现**（§0.1/§0.9，先例：pysci-jury 撤销）。
- **P-11 改进管道自覆盖，但精确豁免自指**：一切组件走同一条改进管道；豁口只写明确
  （inspector 不自巡其 CLI、twin 不自改权重）（§0.2）。
- **P-12 宁可粗糙但在用**。最小占位版先跑通流程，正式化留待框架稳定（先例：reviewer
  rubric 现阶段为最小占位版，2026-10-09 裁决）。
- **P-13 Harness 预算是硬约束**：全量注入档/常驻暴露档/按需档每文件 ≤8192B（落盘字节）；
  超限说明设计过于复杂——正确反应是拆分或重新设计使用方式，**不是放宽预算**；用户裁决
  「严格执行」（basic.md §1）。
- **P-14 不创建未被要求的文件**（不写 README/说明文档/demo/example），用法写进 docstring
  与注释（basic.md §5）。
- **P-15 分层与命名一致性**：`src/pysci/` 只定义、`scripts/` 只使用；变量名优先 Unicode
  并与文献一致；资产路径统一走 `pysci.paths`，不散落（basic.md §5）。

## D. 观测、验收与安全边界

- **P-16 观测面不得静默退化**。fail-open 分支必须留痕标签；哨兵要用真组件直跑（node 跑
  真 guard、subprocess 跑真 CLI）而不是 mock 自证——首版 delivery-gate 的 TDZ 事故 13 例
  违规全绿通过是既定教训。
- **P-17 实测裁决优先于推理**。两方案僵持时用可执行命令的实测输出裁决，不另开会话问第三
  个意见；审查类任务只报有证据的问题，未发现问题直接答「无缺陷」（basic.md §2）。
- **P-18 验收=成员声明式 + 组长可抽检**。硬 QA 门已取消改可选 reviewer；机械验收不得
  阻碍灵活任务（README §13 2026-10-07）。
- **P-19 事件驱动，零轮询**。长任务走后台通道 + 原生通知唤醒；`sleep` 轮询是错误形态
  （README §13 2026-10-07 等待模型 + 2026-10-10 watch 硬化）。
- **P-20 护栏级配置须显式授权**：README 红线/审批权/角色边界/门禁策略、registry models
  渠道绑定、他人只读层、根 rules §1——改动须经用户；其余机制面可由维护者自改（charter 纪律）。
- **P-21 网络默认直连**：访问期刊数据库/正版全文绝对禁止代理；仅站点不可达时单命令注入
  本机代理，禁止持久化（basic.md §4）。密钥类（如 SiliconFlow Key）只由用户提供、永不入库。
