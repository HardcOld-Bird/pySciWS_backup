# REFACTOR 施工 M1：TUI 选型 spike + 裸 pysci 入口

（计划 refactor-20261014 环节 m1；蓝图=仓库根 `REFACTOR.md`，先读 §2.1 / §2.3 / §2.5）

## 背景

REFACTOR.md（仓库根，2026-10-14 用户批准）：`pysci-mirror` 改造为裸 `pysci` 交互式 TUI。
本环节是第一步：**技术选型 spike + 入口**。完整主菜单是 m2 的事，本环节只做骨架。

## 目标（三件，缺一不验收）

1. **依赖选型实测（spike）**：为交互面选 TUI 栈。主选 `textual`；退路 `rich`+`prompt_toolkit`。
   - textual 入 `pyproject.toml` dependencies，旁注 ADR 注释（选了什么、弃了什么、为什么——
     本项目惯例：决策记录写在决策发生的文件里）；
   - 最小 spike 应用（模块列表 + ↑↓ 选择高亮 + Enter 进详情占位 + Esc 返回）落
     `src/pysci/skills/orchestration/tools/tui/`（app.py 门面）——**这是 m2 的地基，
     不是一次性脚本**，结构按 REFACTOR.md §2.5（数据层复用 mirror.py 纯函数，不重写读数）；
   - 自动化证据：Textual Pilot 键盘导航测试入 `tests/`（模拟 ↑↓/Enter/Esc，断言选中态与
     视图切换）；启动→渲染→干净退出冒烟（无异常、无残留终端状态）；
   - 无法 headless 验证的**实机终端残余风险**（Git Bash/mintty、Windows Terminal、
     PowerShell 5.1）在结论里如实标注，不许断言「全部兼容」；
   - 若 Textual 在本机环境有不可用实锤（import 失败/启动崩溃/Pilot 不可用），按退路改
     rich+prompt_toolkit，ADR 注释相应改写。
2. **裸 `pysci` console script**（pyproject `[project.scripts]`）：
   - `pysci` + tty → TUI 骨架（上述 spike 应用）；
   - `pysci` + 非 tty → 等价 `pysci status` 静态输出（复用 `mirror.cmd_status`，勿重写）；
   - `pysci-mirror` 本环节**不动**（m7 统一清扫）；`pysci status|journal|decisions`
     子命令保持现状（m7 转 LLM 通道）。
3. **spike 结论写回 `REFACTOR.md` §2.3**：复现命令 + 实际输出摘要 + 结论
   （Textual 定案，或退路生效及原因）。只改该小节，不动蓝图其余裁决。

## 验收预期（机械）

- `uv run --no-sync pytest` 相关用例通过（含 Pilot 导航测试）；
- `pysci-dev venv-sync` 后 `pysci` 入口存在；非 tty 下 `pysci` 打印 status 读数行、退出码 0；
- REFACTOR.md §2.3 含复现命令与实测输出；
- pyproject.toml 依赖变更旁有 ADR 注释。

## 纪律（违约即返工）

- **改 pyproject.toml 后必须先 `pysci-dev venv-sync`**（basic.md §3 入口锁坑：裸 `uv run`
  隐式 sync 在 Windows 撞运行中 exe 锁、先删其余入口，工具面集体失联）；
- CLI 调用首选裸 `pysci-X`，不存在再 `uv run --no-sync pysci-X`，裸名只试一次；
- 编辑项目文件用文件编辑工具，不用 shell 重定向；
- 交互文案/模型遵循 REFACTOR.md §2.2（本环节骨架最小实现即可）；
- 交付按 pod 交付协议 XML（`<result>`/`<blocked>`）；blocked 带 tags 与 reason；
  改进建议带合法 `kind` 属性。
