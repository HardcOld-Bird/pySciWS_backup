## 目标（三件，缺一不验收）

1. **美学统一（全 TUI 一套视觉语言）**：
   - 概览板（`#summary`）、详情页（`#detail`）、口述面（`#journal`）、任务书面板
     （`#taskbook`/`#tb-new`）与主菜单同一套设计语言：圆角边框、`$accent` 色系、
     背景层、标题栏、装饰元素（选中高亮/徽标样式同源）；
   - 抽**主题变量/共享 CSS 常量**（一处定义全 TUI 引用，不许各面板各写一套）；
   - 详情页按内容分区呈现（标题栏 + 读数区 + 操作提示区），不再一坨纯文本；
   - 「朝精美努力」是开放目标：布局/配色细节自定，但**一致性是硬要求**。
2. **用户路径键位矩阵测试**（扩 f1 骨架）：菜单 → Enter 每模块 → 该视图 footer 广告的
   **每一个键**逐一按下并断言可观察效果；反向断言：未广告的键无副作用。文案一致性
   （footer 广告 vs `check_action` 守卫）测试覆盖全 action 表。
3. **视觉结构回归**：CSS 类/组件结构断言（主题变量存在、各面板引用共享常量、组件 id
   齐全），不做像素比对；防「改美学塌结构」。
