# 环节任务书：G1.l1 —— 文献获取与图片提取

## 背景

本环节属于大任务 tb-20261018-212705-ppt（开题PPT制作）的素材准备环。原始任务书全文
已随本任务书附送（「要求与历史总览」），**入选文献的完整清单以其第 3 节下嵌的 markdown
清单为准**（一级标题=页码与标题，二级标题=焦点块，正文=引用条目），本文件不复抄清单、
只规定本环节的交付面。产出供后续 PPT 组装环节（w2）与重制环节使用。

## 工作要求

1. **获取文献**：对清单中全部 34 条引用（含少量跨页重复条目，逐条覆盖、可去重获取）
   逐篇获取全文 PDF。获取顺序：先查**本地 skill 缓存与本地文献库（非 zotero）**，缺者
   再网络检索下载（正版全文/期刊数据库**禁止走代理**，见 basic.md §4）。
2. **录入 zotero**：建议将获取到的文献同步录入本地 zotero 文献库（本地 zotero 已开启）。
3. **提取图片**：对需要提取的条目，从 PDF 提取论文 figure（**高清版**，优先矢量或
   ≥300dpi 位图），落盘到 `data/大任务/5_开题PPT/文献图片/`，子目录按
   **「页码-焦点块-文章」**层级组织（如 `第4页-局域超构表面-PhysRevApplied.2.064002/`），
   同一文章多个 figure 分文件命名（fig1/fig2…）。
4. **豁免项（不提取图片，仅获取文献）**：
   - 第3页「声学超构材料」3 篇（草稿占位图保留）；
   - 第7页全部 5 条（本页仅右侧大图保留、无需提取）；
   - 第3页「传统材料」无文献。
   其余条目（约 26 篇）均需提取。
5. **失败处理**：获取失败或提取失败**不得卡死**——逐条记录（页码-焦点块-文章、来源尝试、
   失败原因）于报告，供 w2 回退草稿占位图。若失败源于基础设施缺口（提取工具缺失/不可用、
   下载通道缺陷等），按交付协议发 `<infra_suggestion kind="defect">`。

## 白名单

- `data/大任务/5_开题PPT/文献图片/获取报告.md` 存在，含：
  - **页码→焦点块→文章→图片目录/文件（或失败）总表**（高频查阅维度集中呈现——w2 将
    按此表逐条找图，不得散落）；
  - 失败清单与原因、zotero 录入结果。
