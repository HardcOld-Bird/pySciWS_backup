4. **版式**：按原始任务书的页码-焦点块-文献布局落位；可在草稿布局基础上优化，但**焦点块
   尽量填满页面、不留大块空白**（如主模板第3/4页）；纯文字极简——仅焦点块标题与必要
   公式；字体/文本框位置尺寸/图片描边按预设速查表逐一落实。
5. **缩略引用文本框**：每页入选文献（含豁免提取与回退占位的）**全部**以缩略引用形式列
   于页底文本框（样式照「个人改进PPT模板.pptx」第3/4页底部：10 pt、`[n]` 编号、2–3 行）。
6. **焦点块动画（重点）**：第 3–10 页按预设 §5 实现——每页按焦点块分组，第 1 块随页自动
   聚焦（onBegin），单击逐块切换；聚焦 `#8496B0` 250ms、失焦 `#ADB9CA`/`#D6DCE4` 1000ms、
   delay 0 同时起；缓动统一 ease-out（decel=100000）；页面切换 fade 350ms。参数风格与
   模板第3/4页一致（XML 打靶方法见预设 §5 复现步骤）。
7. **机械闸与渲染自检**：按预设 §7 终检红线自跑（渲染出图 + verify/geometry 机械闸），
   逐页 Read 目检第 3–10 页后再交付；动画效果本身免终检（用户手工检查），但 timing XML
   结构须完整。
8. 仍遇工具/基建缺口（如动画 XML 打靶工具缺失）：发 `<infra_suggestion>`，问题处用合理
   降级并在报告留档。
