# 任务：空终端根治——无控制台派生链的 spawn 全面隐藏化（wake-bind-20261018 s1-noconsole）

## 目标

用户实测（2026-10-18，夜航执行大任务返工期间）：桌面反复弹出**空终端窗口**，标题为
本项目 venv 的 python 解释器（`.venv\Scripts\python.exe`）。项目惯例：一切后台任务
的终端必须隐藏。本单根治其产生链并防再漏。

根因链（组长已逐处实测核验，行号以当前 HEAD 为准）：

1. Windows 上，**无控制台**父进程（pythonw 驱动的看门狗 tick、`DETACHED_PROCESS`
   分离进程、GUI 子系统进程）spawn 控制台子系统 exe 且不带 `CREATE_NO_WINDOW` →
   系统分配**新的可见控制台**，窗口标题=分配方 exe 路径；
2. `watchdog._rearm`（src/pysci/skills/orchestration/tools/watchdog.py:142-168）经
   `drain._spawn_detached`（`DETACHED_PROCESS|CREATE_NO_WINDOW` ⇒ bash **完全无
   控制台**）拉起 `bash .qoder/hooks/watch-arm.sh`；
3. `watch-arm.sh` 内多处**裸 spawn** venv exe：`"$PY" -m ...night --diff`（:83）、
   `"$ORCH" wake-claim --check`（:68/:98）、`"$ORCH" watchdog start`（:111）、
   `"$ORCH" watch --timeout ...`（:130）→ 每次看门狗重臂/钩子触发即闪一个空终端，
   标题恰为 python.exe（`"$PY"` 即 `.venv/Scripts/python.exe`），与现象逐字吻合；
   夜航大任务返工期 listener 频繁失联 → 看门狗反复重臂 → 反复闪窗。
4. 同类裸 spawn：`.qoder/hooks/night-gate.sh:22`、`.qoder/hooks/night-policy.sh:19`
   （`"$PY" -m ...night`）——harness 钩子执行体若无控制台同理闪窗。
5. 低频遗留裸 spawn（父进程多带隐藏控制台、风险低，同单顺手清点）：
   `src/pysci/skills/devops/tools/mdgen.py`（`subprocess.run([sys.executable, "-m",
   "pre_commit", ...])`，直接拉 venv python.exe）、
   `src/pysci/skills/orchestration/tools/turnbudget.py:205-208`（sys.executable
   spawn PostToolUse 钩子）、`tui/app.py:163`（裸 Popen 起 VS Code——交互可见属
   预期，可豁免但须注明）。

## 工作项

1. **钩子脚本 spawn 隐藏化（根治面）**：`watch-arm.sh`/`night-gate.sh`/
   `night-policy.sh` 一切 venv exe 调用不得分配新可见控制台。推荐口径：改用
   `pythonw.exe`（GUI 子系统，永不分配控制台）——上述调用的 stdout/stderr 均已
   重定向到管道/日志，pythonw 安全；`night` 已走 `-m`，`orch` 有 `__main__` 守卫
   （orch.py:1860）可改 `"$PYW" -m pysci.skills.orchestration.tools.orch`。**注意**：
   pythonw 下 stdout 未重定向会静默丢写——每处调用保持现有重定向；命令替换与
   exit 2 的 stderr 注入语义逐条不变；对 pysci-orch.exe 若依赖 console script 特有
   行为，逐处实测比对退出码/输出。
2. **无控制台派生链清点**：以「父进程无控制台（pythonw tick / DETACHED 分离 worker /
   harness 钩子执行体 / 孙进程层级）可达」为判据，全树 grep 清点
   `subprocess.run/Popen`、`os.system`、`os.popen`、`multiprocessing` 裸 spawn，
   逐处并入隐藏口径。orchestration/tools 已有唯一口径 `procs.run_hidden/popen_hidden`
   （win32 恒 `CREATE_NO_WINDOW`）；跨包复用它或提取共享实现——**同一能力不留两份
   实现**。豁免须逐条注明理由。
3. **回归钉子（防再漏）**：仿 tests/skills/orchestration/test_unmerged_worktree_alert.py
   判据①扩展用例：①钩子脚本中 python/orch 调用必须走 pythonw 或隐藏口径（grep
   钉子）；②全树（除口径实现与显式豁免外）无裸 spawn 硬闸覆盖本单新增站点。
4. **POSIX 行为零变化**：隐藏旗标/启动器切换只影响 win32 分支或 Windows 专用钩子脚本。

## 测试与合并
