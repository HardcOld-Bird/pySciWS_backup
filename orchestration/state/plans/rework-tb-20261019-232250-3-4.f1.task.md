# 环节任务书：f1 —— 雷达图×3（二合一指向性极坐标，r4）

## 目标

用 sim1 雷达数据绘制**三组二合一指向性雷达图**（每组图含 L/R 两条线轮廓同轴），
作为大图装配（f3）第三行子图；单图即按最终子图质量出图。

## 数据（只读）

- `data/research/1_gain_ep/simulation/radar_8period/`：三组 × L/R，1° 分辨率
  （181 点 0–180°），CSV 列 `angle_deg,L,R`＋schema；
- 工具面优先用 `pysci.research.gain_ep.simulation.farfield`
  （`load_comsol_csv`/`groups_from_comsol_csvs`/`validate_angle_grid`）；旧图
  `beam_scatter_combined.png` 只作惯例对照，**不取其数据处理**。

## 绘图要求

1. **二合一**：每组一图，L/R 两线同轴双色（L-incidence / R-incidence，配色与
   dr1 审美参考一致），0–180° 半圆极坐标、1° 网格；
2. **线性标度**（禁对数/禁 symlog）；**组内 scale 适配**——每图极径上限取本组
   L/R 最大值的 nice 上取整（三组最大值不同，禁止跨组统一量程）；
3. **图例置图下**（禁止置于图上/图右）；
4. **主瓣复核读数表**（随交付报告）：每组 L/R 主瓣角与幅值、最强旁瓣、
   L/R 镜像相关系数；物理预期（rv 判据输入，非硬性通过条件）：组 2（groove,
   no gain）L/R 近镜像对称且主瓣强于旁瓣，组 1/3 主瓣指向 45°/135°（组 3 非对称
   但能量集中 45°/135°）；
5. 美学遵循 dr1 审美参考：`data/research/1_gain_ep/article/artwork/
   beam_scatter_审美参考.设计说明.md`＋同目录两张参考图（雷达双色曲线/图例置下/
   线型留白）；sci 风格、零遮挡铁律。
