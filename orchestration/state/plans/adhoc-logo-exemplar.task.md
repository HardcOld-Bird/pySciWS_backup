# 单体任务书：p4–p10 徽标完全模仿 p3 重建样例（四参数）

## 背景

用户手动删除重建了 p3 徽标（口头改单：「完全模仿它即可」），并要求位置/大小/裁剪/
**图层高度**一并入预设（预设另单）。本单仅改 p4–p10 的徽标层；p3 样例与 p1/p2 不动。

## 样例四参数（p3 徽标 id=5 实测，V5）

| 参数 | 值 |
|---|---|
| 位置 | (x=0.079, y=0.937) in |
| 大小 | 3.861 × 6.299 in |
| 裁剪 | `srcRect l=38699`（仅此一参；右 61.3%；裁后素比 0.613＝框比，等比） |
| 图层高度 | **白卡（矩形: 圆角 2）之上、内容层（首块外框）之下**——spTree 第 3 位 |
| 附加 | alpha 8000（alphaModFix）、图源 md5 a5d9de64 原样 |

## 工作要求

1. p4–p10 共 7 个徽标层（现为完整 1:1 版）：改 bbox→(0.079,0.937,3.861×6.299)、
   加/改 `srcRect l=38699`、alpha 8000 保持；
2. **z 序逐页对齐样例**：各页徽标置于「矩形: 圆角 2」之上、首个内容形状之下
   （各页内容形状不同，取该页第一个焦点块外框/胶囊为下界）；
3. 交付附：逐页读数表（bbox/srcRect/z 位/alpha 改前后）＋渲染目检（与 p3 样例目视
   一致、等比无变形）＋`slides audit --spec` 输出（**预期零 FAIL**——spec 已按样例
   更新期望）＋sha256。
4. 护栏：仅动 7 个徽标形状；外部写入（WPS）即停报。

## 白名单

仅可写 `data/大任务/5_开题PPT/`（spec/素材只读）。

## success_criteria

- 7 页徽标四参数与 p3 样例逐值一致（bbox ±0.02、srcRect l=38699±100、z=白卡上内容下）；
  audit 零 FAIL；p1/p2/p3 与其余内容零变动。
