## 工作要求（p3）

1. **装饰三层恢复**（不变量，本页起逐页恢复）：按 spec `invariants`/p3 装饰指纹从模板
   复制三层页形状（灰粗边框 [0,0,13.33,7.50]、白卡 [0.09,0.09,13.25,7.42]、院徽
   [0.08,0.94,3.94,7.24] 含 alpha），置于内容层之下。
2. **字体全槽修复**：p3 全部 run（标题/胶囊/正文/引用框）补 `<a:ea>`（+cs/panose，照
   spec 字体条目；用 a5 的 `slides_fonts.copy_font_slots` API）。
3. **一般 1 圆角实验**（可选，试于本页三焦点块）：外框试小圆角（参照单图块形式）；
   若视觉效果不优于直角，保留直角并在报告说明对比结论（供 d_preset 定夺入预设）。
4. 图槽/引用框/标题等 p3 相关 FAIL 行逐条修平（见 `deck-spec-audit.md` p3 段）。
5. **交付必附** `slides audit --spec` 本页输出（PASS/人工确认行齐全、无 FAIL）。
