   （BINDINGS app.py:49），但 `action_tb_new` 有守卫 `view != "taskbooks"` 即静默
   return（app.py:339）。主菜单 Enter 进「任务书」模块走的是 `_open_detail`（通用
   详情视图），不是专用面板 `t`——用户按 `n` 无任何反应。测试只走了 `t`→`n` 面板
   路径（test_taskbooks.py:196），**菜单→Enter→按键的用户路径零覆盖**。
2. **占位未兑现**：modules.py 留着「（细节 m3 补）」×4（队列:176/盲审:187/系统:205/
   待决:222）、「（占位）…m5 充实」（计划与派发:163）——m3/m5 任务书均未含兑现条款，
   是拆解遗漏 + 失实承诺文案。

   - 「任务书」模块 Enter **直达专用面板**（= `t` 的 `_open_taskbooks`，Esc 返回菜单；
     `t` 保留全局快捷）；`n`/`a`/`r` 的守卫视图与入口统一；
