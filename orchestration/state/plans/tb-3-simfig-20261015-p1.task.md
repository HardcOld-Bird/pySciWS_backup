# 任务书 tb-3-simfig-20261015 · P.p1：COMSOL 外场/远场计算修正与高分辨导出

## 背景
大任务 tb-20261015-194834-3（3 综合仿真实验绘图任务）：旧版综合图的远场极坐标子图存在
两类缺陷——①散射主瓣指向偏离物理预期（疑似近场污染：外场计算评估点距仿真区中心过近）；
②角度分辨率低。且远场只有 COMSOL 原生 PNG 栅格、无数值数据（下游无法做双色合并与自适应
标度）。上游 I.i2 已为 `pysci-simulation` 新增 `export polar` 子命令（角度序列 CSV 导出），
数值正确性注明由本环节实机首跑核准。

**必读输入**：
- `data/大任务/3_综合仿真实验绘图任务/基础设施缺口分析报告.md`（G1/G2 段——缺陷根因分析）
- `data/大任务/3_综合仿真实验绘图任务/基础设施改进记录.md`（`export polar` 命令面与参数）
- `data/大任务/3_综合仿真实验绘图任务/校准审查报告.md`（P2/P4d 与 §4.5：注意
  `export_image(clean=True)` **不去除** COMSOL logo——若重导 PNG 须自行去品牌区，或干脆不导 PNG）

## 目标
1. **修正外场计算评估位置**：`acpr.efc1`（ExteriorFieldCalculation）在
   `build_beam_scatter_mph.py` L283-301 创建时未显式设置评估圆距离（只绑 `sel_arc`）。
   在模型/构建脚本中**显式配置**评估圆（移离仿真区域中心、进入远场区，排除近场污染），
   使散射主瓣回到物理指向：**左/右入射的散射主瓣分别明确指向 45° 与 135°**
   （半圆域极坐标约定：0° 沿直径向右、90° 向上；哪侧入射对应哪个角度由模型对称性判定，
   并在核验记录中写明判定依据）。
2. **远场角度分辨率达 1°**（出射半平面角度序列，步长 1°）。
3. **导出 6 份数值 CSV**：3 情形（full=管槽+增益 / nogain=管槽无增益 / nostruct=仅增益管槽）
   × L/R 入射，角度列 + 幅值列（`acpr.efc1.pext` 模），用 I.i2 新增的
   `pysci-simulation export polar` 实现——本环节即其**实机首跑核准**，命令面缺陷如实记录。
4. **核验记录**：每份 CSV 的主瓣角（argmax）、分辨率点数、与 45°/135° 的偏差表；评估圆
   参数改动前后对比；COMSOL 求解是否需重跑（外场计算属后处理特征的话可只重评估）如实记录。
