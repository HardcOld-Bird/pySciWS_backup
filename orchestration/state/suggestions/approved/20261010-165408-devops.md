# 改进建议（devops，待审批）

标题：agentsMdExcludes 生效性缺机械哨兵——doctor 只验字符串、不验实际注入

现象与证据：`agentsMdExcludes` 是 CLI 侧行为，doctor 的巡检只能证明 settings 里写了这条 glob，**不能证明 CLI 真的据此排除了根规则**。本任务两次证明都靠临时 headless 探针（`qoderclicn --cwd <pod> -p <自述问答> -m Qwen3.8-Flash --max-turns 1`，单次约 60–70s，结论依赖模型复述被注入文件的小节标题原文）。这类「机制是否真生效」的验证目前是一次性、口头自述型的：将来若 CLI 改了该配置键的名字或 glob 语义（例如不再支持 `**/` 前缀），十 pod 会静默退回「组员看见组长规程」，而 doctor 仍报全绿——无机械防线。

建议：把探针固化成一条命令（`pysci-dev doctor --probe [--pod <id>]` 或独立 `pysci-dev probe`），用「不可猜标记 + 期望不可见」双断言（正例 basic §1 可见 + 反例 leader-only 不可见），一次派发覆盖全部 pod 并把结论写进台账；同时可让根 rules 文件带机器可检的存在标记（如首行 HTML 注释 token），避免依赖模型复述中文标题。属加分项，非本次缺陷，是否入 backlog 请组长裁。
