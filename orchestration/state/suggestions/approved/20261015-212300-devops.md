# 改进建议（devops，待审批）

kind: usability
delivery: leader-reflection
来源：用户口述裁决（2026-10-15）——「绘图色系克制」通用审美标准入 harnessing

**场景**：用户裁决一条通用科研绘图审美标准——**整图设计用色的色系数量克制，一般 1~2 个
色系**（同一图内红黄蓝绿并用显杂乱，色系克制是提升「高级感」的常用技巧）。要求：
①reviewer 审图标准加入该条（若尚无）；②ai-drawing 与 scientific-plotting 组员的
harnessing 也应了解该技巧。

**证据（复现 → 实际 → 期望）**：
- 复现：grep `色系|color famil|少.*色` 于 `orchestration/pods/reviewer/rubrics/
  scientific-plotting.md`、`orchestration/skills/ai-drawing/SKILL.md`、
  `orchestration/skills/scientific-plotting/SKILL.md` —— **零命中**（三处均无该标准）。
- 实际：现行量表 D5 只有「线色区分度（色觉安全）」，无「全图色系数量」维度；两个技能
  的配色指导只有具体 palette（Okabe-Ito/Tol）与 colormap 层面，无「整体色系克制」原则。
- 期望：三处 harnessing 各有一条可执行的「1~2 色系」表述。

**建议（落点）**：
1. `orchestration/pods/reviewer/rubrics/scientific-plotting.md`：D5/D6（或新条目）加
   「全图设计用色色系克制（一般 1~2 色系）」判定要点（与 #165 的 v0.3 升级并批）；
2. `orchestration/skills/ai-drawing/SKILL.md`：审美参考生成的配色指导加入该技巧；
3. `orchestration/skills/scientific-plotting/SKILL.md`：样式/配色层加入该技巧。

**适用边界（与用户同日既有裁决的协调口径，实现时照此措辞；若用户另有口径以用户为准）**：
用户/领域**指定的数据 colormap**（如本任务用户点名的 COMSOL Rainbow 式场图配色，零值
黄绿居中）作为声明的设计决策，**不计入**色系计数；本条约束的是设计用色（曲线/标注/
边框/背景/装饰），且设计用色应与数据 colormap 观感协调。

success_criteria:
- 三处 harnessing 各有一处「1~2 色系克制」表述（grep「色系」命中 ≥3），含上述适用边界；
- reviewer 量表中该条可执行（有判定方法：数设计用色的色系归属，不数数据 colormap）；
- 技能真本改动经 `pysci-dev sync` 部署；各文件 8KB 预算不破。

**补充（用户指令 2026-10-15，适用边界以本补充为准）**：数据 colormap 豁免色系计数，但**不豁免相协调义务**——当 Rainbow 类数据 colormap 为**必选项**（如本任务用户点名的场图配色）时，设计用色应**取自该 colormap 同族或与其协调的中性色**（如暖/冷同谱点缀、灰阶），**尽量避免添加 Rainbow 之外的其他色系**（如另起紫色系、异调绿等）；「1~2 色系」按「数据 colormap 同族 + 至多 1 个协调点缀色系」执行。三处 harnessing 的表述均按此口径措辞。
