kind: defect（既有机制行为与其声明不符，附复现）

**缺陷 1 — `compose slides verify` 名为「机械视觉验收」，实际对本次两类硬伤零覆盖。**
复现：
```
$ pysci-compose slides verify ".../20260918/20260918.pptx" --render-dir bench/ppt_i3/20260918_render
[slides verify] PASS 20260918.pptx：幻灯片 5 页 / 渲染 5 张   EXIT=0
```
而同一产物的实际缺陷（机械可测）：外框四条边被粘贴截图覆盖 16%–100%、两图重叠 4.78 in²、
固定高文本框文字溢出。声明是「机制保证优先于自觉」（`slides_visual.py:1-13`），实际只防
「忘了渲染」、不防「渲染出来是坏的」——对 rubric 的 H4① 零遮挡铁律（硬伤级）与 H2 溢出无任何
机械支撑，审查员被迫自建脚本（本 pod 已留可运行原型 `bench/ppt_i3/occlusion_scan.py`，38 行
核心逻辑，输入 pptx、输出四条边被覆盖率与覆盖区间；`geom_dump.py` 输出形状 bbox+z 序）。
建议：`verify` 增 `--geometry`（形状 bbox+z 序 → 外框遮挡率/越界/图片互叠），或把
`extract --geometry` 补上，使 H2/H4 的原料不再依赖审查员自建。

**缺陷 2 — `verify` 的渲染目录默认值与 pod 白名单冲突，可复现的强制绕行。**
复现：`default_render_dir()` 取 `<pptx 同目录>/<stem>_render/`（`slides_visual.py:35-42`），
而审查任务白名单为「可写 `orchestration/pods/reviewer` + `data/research/1_gain_ep/汇报PPT/20261016`」，
受审目录 `.../20260918/` 禁写 → 默认渲染即违规。唯一合规路径是 `render --out` +
`verify --render-dir` 双参数手工对齐（本次如此，并须自行记住两个旗标名）。
建议：任务书/白名单显式许可受审产物旁的 `<stem>_render/`，或让渲染目录随交付清单声明而不强绑
pptx 同目录。

**缺陷 3 — H2 判法缺少「字体保真」前提，可能产出假阳性/假阴性。**
复现：受审 deck 标题字体为 `Heiti SC Light`（macOS 专有），本机 `C:/Windows/Fonts` 无此族
（仅有 `msyh*.ttc`/`simhei.ttf`/`NotoSansSC-VF.ttf`），LibreOffice 静默替换 → 渲染图上标题
「·现状总结·」「·今天的AI能做什么·」折行且末行落到标题框外。实测结论：CJK 前进宽度恒 1em
（16 pt → 31 px = 1em）故**水平换行可靠、垂直行距不可靠**；另 `autosize=SHAPE_TO_FIT_TEXT`
的文本框会自增长，PowerPoint 与渲染器结果可不同。本次据此**未**把标题折行计入 H2 硬项
（改用字体已落盘的 `微软雅黑 Light` 证据），但 rubric 未写这条前提，换一个审查员极易误判。
建议 H2 判法补两条：①字体未落盘 → 行距相关判定降级为提示、不作硬项；②`SHAPE_TO_FIT_TEXT`
框不据渲染图判溢出。

**缺陷 4 — 任务书的产物事实由人工手写，与产物实况不符。**
复现：任务书载「用户手工制作，**3 页**」；`pysci-compose slides extract`、`slides render`
与 pptx 幻灯片数三处一致为 **5 页**。审查员若照信将漏审 2 页。建议派发侧从产物机械读出页数
（`slides extract` 已具备该能力）后写入任务书。

**附带**：`state/failure-tags.json` 无「遮挡 / 文字溢出 / 素材质量（断词、无出处）」档位，
本次 FAIL 若需分类只能落 `unknown`（而词表自述「unknown 反复出现即说明该补一项」）；建议在
正式 rubric 颁布时同步增补。

success_criteria: ①`compose slides verify`（或新子命令）对受审 deck 报出遮挡与溢出问题且退出码
非 0，或以 `--geometry` 输出「外框边被覆盖率 / 图元越界 / 图片互叠面积」三项数值，本 pod 的
`occlusion_scan.py`/`geom_dump.py` 可直接移植为参照实现；②存在一条无需手工记旗标的合规渲染路径

`--render-dir` 双参数绕行；③`presentation.md` 的 H2 判法含「字体未落盘 → 行距判定降级」与
