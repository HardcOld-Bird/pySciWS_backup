## 规格

### 1. DeepSeek 谷时判定（官方口径，多源核实 2026-08/09）
- **峰时** = 工作日（周一至周五）9:00–12:00、14:00–18:00（2 倍价）；
- **谷时** = ① 周六日**全天**（调休上班的周末亦然——按星期几判定，is_in_lieu
  无需参与）；② **法定节假日全天**（哪怕落在工作日）；③ 工作日其余时段
  （含 12:00–14:00 午休与夜间）；
- 节假日库：**chinesecalendar**（pip，离线内嵌 2004–2026，含调休），
  `pyproject.toml` 增依赖 + `pysci-dev venv-sync`；覆盖外年份
  NotImplementedError → **保守不切换 + mirror 告警**（不猜、不静默）；
- 时区：北京时间口径；按用户指示用本机时间判定（机器时区非 UTC+8 时以
  zoneinfo Asia/Shanghai 归一换算，配置注记）。

### 2. 切换时机（单跳不可中途换模型 → 早切）
- **进入谷时：即时切换**（12:00、18:00、周末/节假日起点）；
- **进入峰时：提前 1 小时切换**（工作日 8:00、13:00 切回原预设）；
- 切换仅影响**新派发**（在途单跳不受影响）；切换记录入 run 日志与 mirror。

### 3. 隐性 DeepSeek 模式（qwen/mimo 预设内）
- **主席**：全员 = BYOK DeepSeek-Flash（1a54cc57…），无 pro 席——与显式
  deepseek 预设一致；
- **仲裁团**：前两席固定 GLM+KIMI（始终按量付费）；**第三席分模式**：
  - qwen 预设隐性态：**Qwen3.8-Max 经 TokenPlan API**；
  - mimo 预设隐性态：**Mimo-V2.6-Pro 经 TokenPlan API**；
  - 显式 deepseek 预设：Mimo 旗舰，**先 TokenPlan API → 失败再 Mimo 按量**
    （.env `MIMO_API_KEY`，用户稍后补充）；
- 席位配置化（name/base_url/key_env/billing 每席可配），缺 Key → 自动下探
  链下一席 + **双面告警**（调用者+mirror）——沿粘滞降级机制；
- ⚠ 待用户提供（不阻塞主体施工）：Qwen TokenPlan API 与 Mimo TokenPlan API
  的**端点与 Key 变量名**（.env 现无 QWEN_*/MIMO_* 条目）——缺失期第三席
  走「缺 Key 下探」路径并告警。

### 4. 观测面

- 切换事件入决策日志（kind=routing）。
