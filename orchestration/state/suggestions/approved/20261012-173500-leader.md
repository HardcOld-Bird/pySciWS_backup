kind: usability
背景（用户原话）：内置 flash 免费但限速、响应慢影响效率；要求 flash 档映射
**永久**改为优先 BYOK 渠道，内置渠道作为回退（两者地位互换）= 现 flash 与
flash_fallback 的值互换。

规格：
1. registry.models：`flash` ← BYOK Qwen-3.8-Flash UUID（现 flash_fallback 值
   ed6f5996…），`flash_fallback` ← 内置 `Qwen3.8-Flash`；
2. **关键面**：`registry.DEFAULT_MODEL_PATTERNS` 与 `refresh_models()` 的
   「名→档」规则同步互换（BYOK Qwen-3.8-Flash→flash、内置名→flash_fallback）
   ——否则 drain 启动自愈按旧模式表把映射刷回（§3.5 护栏教训：改名/换档须
   更新模式表，这正是那一条的镜像场景）；
3. quota 回退逻辑不动（现 `<tier>_fallback` 机制自动变为「BYOK 耗尽→内置
   免费兜底」，语义恰好更优）；
4. README §3.5 渠道策略行同步改写（BYOK 优先=按量小额、内置=免费回退；
   注记用户裁决日期）；journal 该段同步一句；
5. 在途 drain 会话不打断（用户明示可缓）：新派发自然生效。

success_criteria：
- registry 读数互换 + 一次 `refresh-models`/drain 启动后映射**不被刷回**
  （阳性用例钉住模式表一致性）；
- 一次真实 flash 派发台账 model 字段=BYOK UUID（credits 应恢复计量——
  顺带取证 BYOK flash 的 credits 上报行为并记录）；
- README §3.5 与代码模式表同源（快照断言）；全量无回归。
