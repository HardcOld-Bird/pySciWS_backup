# 改进建议（writing，待审批）

kind: usability
delivery: result

场景：任务书给「右缘 2000→≈1900」「2190→≈2100」这类**固定像素提示值**。
易错点：照搬提示值会与既定目标（"内移到行界、消除半截字"）冲突——本任务实测 ≈1900 会竖切 pr 正文「将/并/以及」末字、≈2100 会竖切 cd「流」，两者都制造新的半截字。
期望形态：对"落点需按素材像素实测校准"的改动，任务书宜给**目标 + 复现锚点**（如"随附复现图/给出末字与残片的像素区间"），或明确"提示值仅为量级参考，以消除目标为准"，避免执行端在"照做 vs 达标"间二选一。
