# 改进建议（leader，待审批）

**（渠道改版，用户裁决 2026-10-12 21:1x）模型路由重构：Mimo 主力双档 + 三级有序回退 + 回退告警面**

kind: usability
success_criteria: 见文末。用户新增订阅自定义模型（qoder setting 已配
contextWindow 1M）：
- `99127e47-626d-421f-b0cb-02ffdbf1ada7` = **Mimo-V2.6-Pro**（max 档第一优先）
- `017036af-b630-498a-bfea-883a20c67e33` = **Mimo-V2.6-Flash**（flash 档第一优先）

规格：
1. **registry.models 从单值升级为有序回退链**（schema 扩展，向后兼容读法）：
   - `max`  = [Mimo-V2.6-Pro(99127e47…), BYOK Qwen-3.8-Max(982ae403…), 内置默认]
   - `flash` = [Mimo-V2.6-Flash(017036af…), BYOK Qwen-3.8-Flash(ed6f5996…), 内置 Qwen3.8-Flash]
   - `minimum` = [Mimo-V2.6-Flash, 内置 Qwen3.8-Flash]（压测最低成本档，Qwen BYOK 不进链——额度宝贵）
   - `flash_fallback` 键并入 flash 链（旧键兼容读，新写走链形态）；
2. **DEFAULT_MODEL_PATTERNS 增补**：`Mimo-V2.6-Pro→max`、`Mimo-V2.6-Flash→flash
   +minimum`（名→档规则表同步，防自愈翻转——#74 教训已实证）；
3. **回退触发**：当前席不可用（quota/channel_error/启动即失败）→ 自动换下一席
   重试一次/席；全链耗尽 → 全局停止（沿 #77 的 CHANNEL-STOP 语义）；
4. **告警面（用户裁决，双面）**：每次**降级回退**发生时——
   a. 调用者面：dispatch/envelope 侧输出 `[!] 档位回退：<tier> 席<名>不可用
      → 已切换 <新席名>`（run 日志+交付告警）；
   b. mirror 面：`pysci-mirror status` 判决包健康段新增「渠道回退事件」计数
      与最近 N 条（含时间戳/档位/原席→新席/原因）；
5. **观察期注记**：组员当前全部 flash 档（用户明示暂不升档），max 链仅
   deputy/reviewer 按需升档与组长侧使用；
6. README §3.5 渠道策略行改写（Mimo 主力、Qwen 回退、内置兜底、回退必告警）。

success_criteria：
- registry 链形态读数正确（三档三席排序）+ `refresh-models` 后不被刷回
  （阳性断言含 Mimo 名→档规则）；
- 构造「首席不可用」场景（monkeypatch 或断网）→ 断言自动降级+调用者告警行+
  mirror 事件落账；全链耗尽 → CHANNEL-STOP 而非逐单烧账；
- 一次真实 flash 派发（Mimo-V2.6-Flash）台账 model 字段可证；一次真实 max
  派发同证；
- 旧 flash_fallback 键兼容读不报错；全量无回归。

**补充（用户 2026-10-12 21:3x）**：BYOK Qwen 渠道余额**暂不充值，将持续不可用**
（用户主力转 Mimo）。据此增加降级粘滞设计：某档某席探测失败后，该席进入
**短窗跳过**（registry 记 fail_ts，N 小时内同档直接走下一席），期间每次派发
仍输出一次「席 X 跳过中（20:xx 故障，窗口内不重试）」告警——既省探测跳数，
又不丢 mirror 侧的故障可查性。窗口过期自动恢复探测（用户充值/修好后自愈，
无需改代码）。success_criteria 补一条：注入一席故障 → 首次探测+告警、窗口内
第二次派发零探测直落内置、窗口过期恢复探测。
