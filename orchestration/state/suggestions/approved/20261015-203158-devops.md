# 改进建议（devops，待审批）

kind: usability
delivery: result

kind: usability
success_criteria: 明确「可选依赖 extra（如 ai_drawing 的 `[imaging]`）」在 `venv-sync`（uv sync）下的存活策略，或在文档中标注其为「需按需临时安装、会被 sync 清除」的脆弱状态。

场景：`pysci-imagine doctor` 显示 `scikit-image`/`opencv`（`[imaging]` extra）未安装，导致 7 个纯本地算子不可用；按文档 `uv pip install -e ".[imaging]"` 装上后，下一次 `pysci-dev venv-sync`（或裸 `uv sync`）会因「extra 不在默认依赖集」而将其移除——安装即短暂、不可复现。当前文档未提示这一点，使用者会反复经历「装了又没了」。建议二选一：把常用 extra 纳入默认依赖，或在 doctor/技能文档显式标注该脆弱性。属策略面，本环节未擅自改依赖。
