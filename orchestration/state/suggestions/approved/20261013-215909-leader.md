kind: usability

- `orch requeue <id> [--note]`：needs_leader → pending 并唤醒 drain（等价于内部 wake_devops）；
- `orch resolve <id> --note "<为何销账>"`：组长确认达标 → done（原 blocked 事实保留于 note 与 git 历史）。
