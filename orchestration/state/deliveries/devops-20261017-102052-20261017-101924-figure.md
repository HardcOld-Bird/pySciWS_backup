## 根因与修法

`pysci-figures overlap` 在大图上**慢且无输出**。实测剖分（真图对 2880×1440）：`render_ink_verdict` 31.6 s，其中 **`min_distance_px` 占 31.2 s**（分块全对全 `O(N·M)`：墨迹 29,733 × 图线 46,902）；蒙版/交集合计仅 ~0.5 s。叠加 stdout 重定向的**块缓冲**，进程长时间无任何输出 → 被当成挂死。按建议的三条出口实现：

1. **逐阶段进度（强制 flush）**：`render_ink_verdict` 增 `progress` 回调（`蒙版 → 交集 → 最近距 → 汇总`）；`cmd_overlap` 用 `_ProgressTicker` 线程每 **15 s** 打印一行「当前阶段 + 已用秒」，**所有 print 均 `flush=True`**（重定向日志 `tail` 可即时看到）。
2. **`--downsample {1,2,4}`（默认 1，点采样）**：大图先粗判；报告头与原图/估算后 dpi 一并写出。
3. **报告头写明判据尺度**：`受审图 …：原图 2880×1440 px @ 300 dpi → downsample=1/2，判据尺度 1440×720 px（≈150 dpi）`，读数行标注 `@尺度 1/k`，`--mm-per-px` 随尺度折算（mm 读数不失真）。
4. `-h` epilog 注明「4k 级成品全分辨率约需数分钟；大图先用 `--downsample 2` 粗判」。
