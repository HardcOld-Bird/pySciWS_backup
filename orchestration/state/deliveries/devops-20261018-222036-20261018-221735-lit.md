## 根因与改动
**① 机构权益直链可通、CLI 判失败**
- 根因：同一 APS 直链 `curl` 得 **200/685 KB**，而 Python `requests` 无论换 UA/Accept 都被 Cloudflare 按 TLS 指纹拦成 **403**；且 OpenAlex 会把 DOI 小写化（`physrevlett.117.034301`），而 APS 路径**区分大小写**（小写 → 404）。
- 改动 `research.py`：
  - `_publisher_pdf_candidates`：按 DOI 推导 APS（`journals.aps.org/<abbr>/pdf/<DOI>`，`PhysRevLett→prl`、`PhysRevX→prx`、`PhysRevApplied→prapplied`…，并按规范期刊名还原大小写）与 Science（`science.org/doi/pdf/<DOI>`）直链；
  - `_curl_download_pdf`：curl 直连（`--noproxy *` **禁代理**，符合期刊数据库直连纪律），校验 HTTP 200 + PDF 魔数；curl 不可用/失败才退回 requests；
  - `read` 的直链候选 = OpenAlex `oa_url` + 出版商直链，全部失败才起浏览器/OA 回退；dest 按 DOI 稳定命名。

**② 缓存拾取映射缺失**
- `cache_manager.find_cached_pdf`：统一扫描 `cache/pdfs/`（含 theme 子目录）与 `cache/html_fulltext/<目录>/*.pdf`（目录名按 DOI 归一匹配，兼容 `10.1038_490472a`/`10-1038-490472a`），返回 mtime 最新者；
- 新增 CLI `pysci-research cache find <DOI>`（命中打印路径+大小，未命中 rc=1），供批处理复用；
- 文档 `read-02-…md` 增机构直链与 cache find 说明。
