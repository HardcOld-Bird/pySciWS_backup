## ① 无法枚举物理接口可创建的子特征类型

**关键事实（先交代）**：COMSOL **没有**「枚举某接口允许的子特征类型」的 API——Programming Reference 里与子特征相关的只有 `physics(<tag>).feature().create(<itag>,<type>)` / `tags()` / `getType()`（`getAllowedPropertyValues` 只针对**属性值**，不是子类型）；本地手册（`data/skills/comsol_simulation/docs/*.md`）也只写自然语言名（`PerfectlyMatchedBoundary` 在手册中 0 命中）。因此**穷举**不可实现；本单把组员手工的「试建猜」**机械化**，结论以**本模型实测**为准。

- 新增 `pysci-simulation inspect feature-types --mph M --path 'component(comp1).physics(acpr)' [--candidates A B …]`：
  - 无 `--candidates`：列该节点**已有**子特征的 `(tag, getType())` + 提示「COMSOL 无枚举 API，用 --candidates 实测」；
  - 带 `--candidates`：逐个 **trial-create**（探针标签 `_ftprobeN`，建完**即删**；删不掉则 `probes_left` 告警「勿直接保存」），输出 `[√] 可建` / `[✗] 未知特征 ID` —— 即 sim 组员本轮手工试 3 个候选（PMB/BoundaryCondition/PMLBoundary）那套动作的一键版。
- 落点：`src/pysci/skills/comsol_simulation/tools/inspect.py`（`FeatureTypesReport`/`existing_feature_types`/`probe_feature_types`/`_remove_feature`/`format_feature_types`）、`tools/simulation.py`（CLI + 子命令）。
- **help/文档可检索**：`comsol-simulation/references/cli-01-overview.md` 命令表增一行（含用法与「COMSOL 无枚举 API」说明）。

## 诚实残留（请组长裁决是否达标）

① 的判据字面是「**列出该接口允许的子特征 ID（含各新边界条件）**」。受 COMSOL API 限制（无枚举入口），本实现给的是「**已有类型清单 + 对给定候选的实测可建性**」，**不是**穷举全集。若要让「各新边界条件」也自动进清单，只能**维护一份候选目录**（如在 `inspect.py` 内置常见边界条件类型表，逐个 trial-create 实测）——目录本身仍需人工按 COMSOL 版本维护，且手册不含 Java ID，无法从本地资料自动生成。如组长认为「实测探针 + 文档可检索」已覆盖该建议的**痛点**（不再手写试建脚本、结论以模型实测为准），本单即可销账；若要「穷举式列表」，请另立小单维护候选目录。
