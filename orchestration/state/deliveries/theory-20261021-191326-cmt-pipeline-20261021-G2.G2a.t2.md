## 交付正文

G2 快核已完成并落盘；旧稠密装配路径已在同一提交内删除，公共 API 全部保持兼容。

**性能实现**
- **块对角 Schur 消元**：利用 P3 的块对角（每槽严格对角）结构，`A = P3⁻¹(P1+P2·A⁻)` 代入速度方程，主系统由 (N+J·K) 降到 N（EP 名义参数 114×114 → 21×21）。原 87% 耗时在稠密 `np.linalg.solve`，现已消除。
- **共振模保护**：`|1+U| ≤ 1e-10`（U→−1，无损槽的半波共振）不参与除法，保留为 N+Ns 补充块且保留 P3 的微小对角元。实测硬置零会错到相对误差 1e11；修正后与稠密解一致（失败案例 EP 20°/2λ 现为 2.9e-15）。
- **解析积分只算一次**：`I3 = conj(I2)`（k_x、α、x、w 全实）；`P1 = P2[:, n_orders]`（入射阶即参考栅格 m=0）。装配量 P1/P2/I3/V1/V2 与介质、槽深无关。
- **同参数族缓存**：`_cached_assembly`（256）按 (f0, c0, D, 入射角, n_orders, k_modes, x, w) 缓存，`_cached_kernel`（64）缓存端口与各端口装配；c_complex/h 不入键，介质扫描只重算 β/U 与一次 N×N 求解。缓存键含 x/w，构造后改几何会自动重装配。
- **批量接口**：`CMTForwardKernel(params)`（`s_matrix` / `solve` / `s_matrix_many`→(B,P,P)）、`sweep_medium`（固定几何扫介质）、`solve_s_matrix_batch`（种群/多参数集）、保留 `sweep_s_matrix`（多频）、`clear_forward_cache`（基准用）。
- **无新依赖**：numba 未安装；profile 表明瓶颈是稠密求解而非 Python 内核，Schur 消元后已无需编译级手段（按任务“不为用而用”，未改 pyproject/venv）。
