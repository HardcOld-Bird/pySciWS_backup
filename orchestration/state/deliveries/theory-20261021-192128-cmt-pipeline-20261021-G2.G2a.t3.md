## 交付正文

G2a.t3 逆向设计管线已交付：目标 S 规格、约束修复、差分进化（多进程 + 断点续算）、结果导出与 `inverse_design` 表层 API 均落盘；14 维 EP 回收实跑并导出。

**目标 S 规格**（`inverse_design.py`，支持 |M|×|M|）
- `MatrixMatch`：任意复目标矩阵匹配；复误差/幅值误差/相位误差分别加权（相位用 `1−cosΔφ`，|T|=0 元素自动跳过），逐元权重。
- `ZeroElements`：指定矩阵元置零（单向隐身/定向抑制）。
- `JordanBlock`：`mode="trdet"` 用 `|tr²−4det|`（2×2 与 `|λ₁−λ₂|²` 恒等），`mode="gap"` 用最小本征值间隙²（一般维度），均按 RMS(S)² 归一化；另提供 `jordan_structure(S)` 诊断（聚类后比较代数重数与几何重数 `P−rank(S−λI)`，给出 `defective`）——文档说明“本征值合并 ≠ 约当块”，优化用平滑间隙代理、最终解用该诊断复核。
- `CombinedObjective`：按各 term 权重求和，可任意组合。

**约束与优化器**
- `DesignSpace`：`dim=5J−1`（J=3 → 14：h3+w3+x2+cr3+ci3），归一化基因型；解码**修复**槽宽（保下界、按超额比例压缩到 `D−J·min_feature` 预算）与槽位（逐槽夹紧，保证不重叠/尾部硬壁/总宽≤D）；`decode` 仍走 `MetagratingParams` 完整校验（`MetagratingParameterError` 语义不变）。
- 自研 DE/rand1/bin（可选 best1）+ `ProcessPoolExecutor` 种群级并行；每代检查点（种群/适应度/收敛史/RNG 状态），`resume=True` 定点续算（与直接跑逐位一致，已测试）。
- 结果导出 `result.npz`（参数/S/收敛史/端口）+ `summary.json`，落 `data/research/1_gain_ep/theory/`（data 路径自动 `assert_within_data`）。

**验收证据**
