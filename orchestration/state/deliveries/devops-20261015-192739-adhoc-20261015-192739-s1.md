**夜航差分基线缺口修补（SessionStart 顺手落基线）——缺陷封堵 + 7 例回归，全量绿**

== 一、缺陷与修法 ==
**根因**（组长真机实测）：基线原本只由**首个 Stop 钩子**补记；开关若在 SessionStart 之后、首个 Stop 之前被拨动，那次真跳变会被 `--diff` 当作「首次见该会话」吞成基线，**刹车差分静默丢失**（实案：会话起始 on、中途拨 off，`night_seen` 被记成 off，本应产出刹车差分）。

**修法**（单点，`src/pysci/skills/orchestration/tools/night.py`）：
1. 新增 `record_baseline(sid, *, data)`——把**当时**的 `enabled` 值写入 `night_seen[session_id]`（与 `--diff` **同一落点与键**）；
2. **仅在 `SessionStart` 注入路径调**它：`hook_event_name == "SessionStart"`（含载荷缺事件名而按 SessionStart 名义注入的情形）才落基线；**`PostCompact` 只补注入、不动读数**——它若重写基线，就会把「SessionStart → 拨动 → 下一次注入」之间的跳变盖掉（同族形态，已在实现注释与用例里双向钉死）；
3. 载荷取 `session_id`（原来只取事件名）；无 sid / 读开关异常 → **不落基线**、零输出（fail-open 与既有口径一致）；
4. `.qoder/hooks/` **无需改动**（`night-policy.sh` 已把 stdin 载荷转给 `night.py`）——但这条前提接线被新用例钉住，防日后被删而导致缺陷原样复发。
