## 20261015-204911（defect）：`export image --clean` 未清 COMSOL 品牌 logo

**根因**：`clean` 只关了绘图组的 colorbar/图例/标题，**从未碰品牌**——而 logo 是 **Image 导出节点**上的组件，不是一个绘图组属性。于是现场脚本传了 `clean=True` 仍出带 logo 的图（`raw/far_full_L.png` 角区品牌像素 **80 个**），6 张远场 PNG 全带入最终综合图 → reviewer 判 H3 FAIL。

**修法：原生优先 + 像素兜底（两手都要）**

1. **原生**：新增 `_apply_clean_brand()`，在 Image 导出节点上置 `options1d/2d/3d=on` + `logo1d/2d/3d=off`——依据 COMSOL 手册「Image (Export)」属性表（`logo*d` 是 optional component，**须先开 `options*d`** 才受控，默认 logo*d=on）。属性名不存在时静默跳过（版本差异），交给第 2 手兜底。
2. **兜底（保证判据）**：`postprocess` 新增 `find_brand_box` / `strip_brand` / `count_brand_pixels`——导出后扫**右上角窗口**，**蓝+黄成对**才判为品牌（防色标/等高线的单色误报），命中即用**周边底色中位数**（坐标掩膜取样，自适应深浅背景）抹除，并在 **sidecar 记 `brand` 读数 + 附 warning**（明示「原生开关未生效，已像素抹除」）。

**语义与开关**：`clean=True` **隐含**清品牌（现场脚本不可改、只传 clean，故必须这样才真修好；已在 `-h` 与文档写明），另加**独立** `--strip-brand`（不动其余 clean 项）。不传时默认**跟随 clean**，即 `clean=False` 且不传 `--strip-brand` → 像素零改动（旧行为不变）。
