## 4O. 默认美学风格（四项常量 + 块底规则）

| 维度 | 默认值 | 判定/说明 |
|---|---|---|
| 徽标水印 | `bbox=[0.76, 0.937, 3.18, 5.836]` in（宽高比 `0.5449`） | 与 p1/p2 基准一致（用户批语：位置和比例完全正确）；`alpha=8000`、置底；**禁拉伸**，所有页面同一 bbox |
| 粗外框 | `roundRect`，`adj=3000`（`adj_tol=500`） | 判定口径：描边 ≥5 pt 且宽 ≥2 in；3000 为默认美学暂定值，用户可一句话改参重跑 |
| 外框上缘 | `top=0.94` in（`tol=0.02`） | 自动切分的可排版区域上界（替代旧 `1.00`） |
| 块底 | **本页引用框上缘 − 0.16 in** | 满版间隙不变量。R4 实证：统一底会压 p8 引用框、p10 留空带（w3 教训） |
| 页标题 | `left=0.30` in；右缘 `0.34n + 1.069` in（`tol=0.1`） | n＝标题**非空白字符数**；p3 用户样例 n=6→`3.109` 定标，线性；**替代旧宽公式 `0.34n+0.55`** |

- p3：`6.794 − 0.16 = 6.634`；p4：`6.964 − 0.16 = 6.804`；
- p8：`6.624 − 0.16 = 6.464`；p10：`7.134 − 0.16 = 6.974`。

**标题复算**：n=6 → `0.34×6 + 1.069 = 3.109`（left 0.30、宽 2.809，即 p3 用户样例）。

## 4P. R1 框宽字间距方案的 WPS 注意

R1 的「`algn=dist` + 框宽公式（框长效应产生微字间距）」在 WPS 往返保存后，
框宽/字间距可能被重算或丢失（与字体槽同类风险）。纪律：

- 改后以 **XML 真值 + `slides audit`** 为准，不只信渲染截图；
- 徽标/标题/外框参数只写 `deck-spec.yaml` 的 `aesthetics`，不改代码；
- 改参后重跑 `compose slides audit --spec deck-spec.yaml`，四行零 FAIL 才算收敛。
