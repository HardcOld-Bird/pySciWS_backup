# 组会 PPT 预设方案（presentation preset）

> **单源**：本文件是组会 / 汇报类 PPT 美术设计方案的唯一真本。reviewer 量表与 drawing 技能
> 只挂指针、不复制正文。机械检查：`pysci-compose slides geometry '<deck.pptx>'`
> （标题形态 / 标题框宽适配 / 非整页图描边三项；`--strict` 违规即退出码非 0）。
> 任务书另有更具体规格时以任务书为准；改动本文件须经用户裁决。

**适用**：从 `PPT模板.pptx` 装配的组会汇报、答辩与方案宣讲 deck。

1. **基座**：以任务书指定的 `PPT模板.pptx` **副本**为基座开工——母版纸纹底、主题配色、
   字体与版式阶梯原样继承；不重建模板，不从空白 deck 起笔。
2. **版式纪律**：内容页落**内容版式**（如「仅标题」）；「标题幻灯片」版式**仅用于首页**；
   整页复制页**随源不擅改**（版式、尺寸与既有文字保持源页，只做任务书要求的替换）。
3. **标题**：位置 `(0.60, 0.44) in`、高 `0.44 in`、`44 pt` 等线 Light（`Heiti SC Light`）；
   文本形态「·标题·」（前后各一个「·」），如 `·现状总结·`、`·pySci·`；
   **框宽随标题文本适应**——黑框恰好包住文字，不折行、不过长；**不得把全篇标题框统一成
   同一宽度**。机械判据：按文本与字号估算宽 vs 实际框宽，容差 ±10%。
4. **图像**：非整页图**加黑色描边**（默认粗细，有即可、不究粗细）；整页 AI 渲染图按 16:9
   满幅铺满画布（无描边、无形变、无黑边）；截图裁剪后放入细线外框，**四边零压线**。
   机械判据：图片缺 `<a:ln>`（或显式 noFill）即 FAIL；面积 ≥ 画布 95% 的满幅图豁免。
5. **文字密度**：正文类文字**每页 ≤ 1 行**、极短标注 `18 pt`；**图讲故事**，避琐碎细节、
   留少量关键细节；长段落与原始报告整段不入页。
6. **结尾页**：以模板现成的「感谢 / 谢谢聆听」页收尾（默认习惯，不自起样式）。
7. **视觉终检红线**：`wpscli` 渲染（`compose slides render`）**逐页 Read** ＋ 机械闸
   （`compose slides verify`、`compose slides geometry --strict`）通过——**不经视觉检查
   不得提交 PPT**。
