# 仿真三原则（勤整理 / 最大化复用 / 人类终检友好）

用户裁决 2026-10-27，适用于一切 COMSOL 仿真任务的组织与交付；SKILL.md 的索引行为入口。
COMSOL 仿真易错，三原则服务同一目标：**方便人类与 Agent 验收和排错**。

## 1. 勤整理原则

- 同一主题的仿真文件应积极分门别类整理。
- 单次新增仿真文件**超过一个**时，就应放进一个合适位置的文件夹中，不散落在目录表面。

## 2. 最大化复用原则

- **能用一个 mph 做到的就不用多个**：同一主题任务多数可由一个仿真文件完成；mph 本身是
  边界明确的容器，省去文件夹管理麻烦。
- **能用同一仿真组件做到的就不拆多组件**：共用部分（几何/材料/网格等）复用同一组设置，
  仅对不同部分拆分。
- 正面样板：14 号把 L/R 入射拆成**同组件内两个波动声学物理场**，共用几何/材料/网格。

## 3. 人类终检友好原则

COMSOL 易错，人类终检必要。仿真文件应**双通道**：

- 输入参数可被脚本自由覆盖，但**打开时的默认参数 = 最终绘图所用参数**（人类无需手动设置）；
- 最终绘图数据可脚本化导出，但 mph 内也应用绘图功能做**类似绘制**（不要求形式与美观度，
  仅供人类核对数据正确性）；
- 人类手动打开后**仅按一次「计算」**即可查看到同样的结果。
- **模型树人类可读性**：结果树节点命名须自解释（如色标载体层 / 场图层分别命名），
  不给终检者留「内容相同的重复节点」式疑惑；新增隐藏/辅助层须在交付说明注明用途。

## 自查（交付前）

- [ ] 本次新增仿真文件 >1 个？→ 已归入主题文件夹，无目录表面散落。
- [ ] 同主题多 mph / 多组件？→ 逐一给出不能合一的理由，否则合并。
- [ ] mph 打开时默认参数 = 绘图参数；mph 内有可对照的类似绘制；一键「计算」即见结果。
- [ ] 结果树节点自解释？新增隐藏/辅助层已在交付说明注明用途？
