# 域几何声明（强制，仿真开工/交付前必填）

> 任务书或交付物必须含 `## 域几何声明` 节，四问逐行写成
> `- **键**：带数值的答案`。缺节、缺键、无数字或用「待补/TBD/—」敷衍 → 不合格。
> 机械检查：`pysci-simulation domain-check <文件.md> [--json]`（四问键齐全＋每问含数值
> ＋激励口径的工作点-EP 偏移子问）。

## 四问（每问必须带数值，不能只写「合理/已检查」）

1. **兼容性**：目标场区/标注范围（如 31 cm 菱形）是否**完整位于有效域内**？给出域边界
   到目标区/标注区的最小边距（m/mm），以及标注是否落在求解域外但在画布内。
2. **覆盖率**：散射体（如超表面 8 周期）占入射面的比例是多少？给出「周期数/总孔径」
   与百分比；**＜100% 必须显式声明原因并请示**，不得默认截断后当作满覆盖。
3. **边界适配**：外场计算若占用外侧边界，**禁用 PML**（PML 要求幅值趋零，外场不满足）
   → 用完美匹配边界（`PerfectlyMatchedBoundary`）或后退的 PML；背景压力场（bpf）的
   选择域必须**排除散射体内部**（散射体/异质体等），只选空气域。写明实际边界类型/选择域。
   后果（2026-10-17 用户裁决留痕）：背景/入射压力场误覆盖散射体内部子域 ⇒ 均一化内部声压 →
   超表面失效——本条是防复发硬口径（bpf 选域照此核）。
4. **激励口径**：入射波束宽度 vs 结构孔径（窄波束/高斯/平面波）是多少？与实验口径
   （换能器/喇叭尺寸、聚焦参数）如何互证？给出波束腰/孔径/实验口径的数值对照。
   **工作点-异常点偏移**（增益/损耗仿真必填）：写出工作点 `(cr, ci)`、最近异常点
   （谱奇点/EP）的 `(cr*, ci*)` 与**偏移读数**（Δcr/Δci 或距离），并注明**寻点判据
   出处**（理论小结/探测脚本路径）。缺任一项即不合格。
   **域变更须重寻**（用户 R5 批语 3）：扩域/换形后须在**新域**重寻异常点并报重寻
   偏移读数；声明写「域版本=…、寻点版本=…」——两者不一致且无重寻读数时
   `domain-check` 给**软告警**（不判 FAIL，但须补重寻读数后方可交付）。

## 材料符号口径（设材料必读；backlog 20261029-002034-sim）

槽介质材料表达式（`matgN`，由建模脚本写入）：

```
soundspeed = 343[m/s]*(crN + ciN*i)      # COMSOL e^{+iωt}
```

推导一行：e^{+iωt} 下 +x 传播 `p ∝ e^{−ikx}`、`k=ω/c=(ω/c0)(cr−i·ci)/(cr²+ci²)` ⇒
`|p| ∝ exp(−(ω/c0)·ci·x/(cr²+ci²))` ⇒ **`ciN<0 = 增益`、`ciN>0 = 损耗`**
（与建模模板「ci<0 为增益点」一致；CMT 模块同为「ci>0=损耗」口径，
含损例 `c=c0(1.005+0.05i)` 即损耗）。

**逐符号等式：模板参数 `ciN` ≡ 模块坐标 `ci`（同号同义：负=增益、正=损耗）**。

⚠ 命名对照表若写「名义 `ci2=+0.05`（增益）」：括号里的「增益」是**槽的物理角色＋幅值
来源**（幅值 0.05，符号在材料定义施加），**不是**参数符号语义——写进 mph 材料参数须取
**`ci2 = −0.05`**。判符号一律用本等式（与建模模板同源核对过），
不要「跑一版看会不会爆」来试符号（2026-10-29 实测：反接即 5 个代表点阈值以上伪迹）。

## 判定与联动

- **缺一问答即交付不合格**；reviewer 的 H7 硬项按本节的四问（含激励口径的
  工作点-EP 偏移子问）逐条核。
- 覆盖率 ＜100%、扩域/移动评估圆、改变 bpf 选择域等都会改变远场结论：声明变化须同步
  重跑黄金自检（平刚性面镜面瓣）并在交付说明中更新数值。
- 本声明是**设置依据表**的一部分；手册推荐设置、实际节点属性与本节数值三者须一致。
