# 复杂视觉任务拆解（plan-decomposition 分册）

> 主册：`plan-decomposition.md`（§2 切分粒度、§7 自查清单）；本册为「视觉检验单元」细则
> （2026-10-19 用户批语固化，a5 实施）。

## V1. 不许一刀

- **多面板科研绘图**：每幅子图一单（一个子图 = 一份任务书 = 一次可验收交付）。
- **PPT 制作**：每页一单，或按**工序**一单（如版式重构 / 动画注入 / 图像替换）；
  整 deck 一刀 = 切太粗，终检与返工无法定位到页。
- **PPT 自研美术素材**（AI 图 / mpl 图 / 思维导图）：每幅一单。
- 同一 `member` 也不例外：per-member FIFO 会串行，但拆单首先保证每叶验收面自包含。

## V2. 拆解前先视觉检查

- 先渲染/查看现状（`slides render` / `slides digest` / 逐页 Read），逐页逐幅列出
  **缺陷清单**（现状图 + 目标规格 + 可复算判据）。
- 缺陷清单即派单单元：一条缺陷 = 一个可验收的视觉修正；不要把「看图找问题」留给
  生产叶。

## V3. 产出与校验分摊

- 标注/比对类前置工作（如「逐页列出替换图清单」）单独成单，不与产出挤在一起。
- 产出叶与终检叶分离：终检可独立复跑（`slides render/verify/layout` + 放映人工核对）。
- 单叶视觉检验量（需人眼/看图判读的页或幅数）超一轮舒适量即继续拆。

## V4. 自查表增补

- [ ] 是否存在**单叶视觉检验量 > 一轮舒适量**？是则按子图/页/幅/工序继续拆。

## V5. 现状断言须附机械读数（返工 3 轮根因 1/2）

- 任务书中凡「现在是什么状态」的断言（尺寸/md5/形状清单/图槽内容/bbox）**必须附可复跑
  的机械读数**：命令 + 原始输出，或读数文件路径；禁止裸断言（「当前是 6 张图」而无
  `figures.json` 行）。
- 读数即派单单元与验收基线：同一命令重跑可对账（`slides extract` / `figures.json` /
  `slides audit --spec` / `crop-img --dry-run` 都是现成读数面）。
- 拆解前先跑读数、列缺陷清单，再切叶——不要把「看图找问题」留给生产叶。

## V6. 索引去建议化（返工 3 轮根因 2）

- 图像索引/现状清单只记**事实**：内容、尺寸、指纹（md5/px）、原文图号、来源路径。
- 剥离「建议选 X / 补充图 Y / 应该用…」类语句；挑选规则唯一：
  **占位符同款 > 原文图号匹配 > 其余**。任何偏移必须在交付报告显式声明理由并经复核
  （建议不得再越权替代规则）。
