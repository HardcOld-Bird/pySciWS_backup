# 禁回退清单组装指引（taskbook-template 分册 02）

> 由 `taskbook-template.md` 按 basic.md §1「超预算即拆分」移出（tb-20261017-212141-3-3
> L.l3 F2）。模板正文留「禁回退清单」段与对照源清单产出位，组装方法在本册。

返工第 ≥2 轮的任务书必附「禁回退清单」。清单**不得凭记忆手抄**——手抄会漏项：本轮
重绘回退把既定标注 `Exp.†` 降级为 `Exp.`，漏掉的正是「角标＋脚注」这类细节惯例
（reviewer H6 抓住）。组装按以下源**逐项列举**：

1. **历轮交付产物（既定做法）**：上轮及历史交付说明/勾核表、返工任务书与批语，以及
   产物本身（图 / PPT / 脚本）。
2. **old prompts / 原始材料惯例**：历史提示词、设计说明、参考图与原始资料中已定的
   标注 / 角标 / 脚注 / 配色 / 图例 / 编号等惯例。
3. **细节惯例显式点名**：逐项写到可勾核的粒度（如「实验标签带 † 角标并配脚注」
   「colorbar 3~5 条且无 ±」「仅第一列示 Exp/Sim 标签」）；「保持原有风格」不算清单项。
4. **对照源清单（强制产出位）**：清单段末列出本次组装**实际对照**的源文件路径
   （历轮交付产物、交付说明、old prompts、参考材料）；未对照的源写明原因。
   **缺对照源清单＝组装不完整**，视为缺理解痕迹。

## 与任务书其余段的衔接

- 本轮批语点名的回退项**置顶**，并在条目后标来源（如「批语 2」）。
- 清单是**验收面**：任务书「交付」段须要求成员附逐条勾核表；reviewer 按清单逐项核对。
- 用户显式指令仍是硬性禁回退项（模板「处置分支声明」），本清单不得收窄其范围。
